5.15. Proof Colors

Enabling Proof Colors allows you to interpret the colors of this view of your image using a soft-proofing profile that you can set using Soft-Proof Profile.

5.15.1. Activating the Command

You can access this command from the main menu through View → Color Management → Proof Colors.
