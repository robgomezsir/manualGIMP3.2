3.22. Keyboard Shortcuts

This command opens the Keyboard Shortcuts Dialog. Using that dialog you can add or change keyboard shortcuts to menu commands, tools, filters etc. A quicker way to change shortcuts to menu commands is described in Section 2, “Creating Shortcuts to Menu Commands”.

3.22.1. Activating the Command

You can access this command from the main menu through Edit → Keyboard Shortcuts.
