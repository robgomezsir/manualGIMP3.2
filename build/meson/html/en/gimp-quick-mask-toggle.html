4.17. Toggle Quick Mask

This command has the same action as clicking on the small button in the bottom left corner of the image. See Quick Mask.

4.17.1. Activating the Command

  • You can access this command from the main menu through Select → Toggle Quick Mask.

  • You can also use the keyboard shortcut Shift+Q.
