8.13. Linear Invert

The Linear Invert command inverts all the color components except the alpha channel in the current layer in linear light. Dark areas become bright and bright areas become dark.

Warning

Do not confuse this command with the Invert Selection command.

8.13.1. Activating the Command

You can access this command from the main menu through Colors → Linear Invert.
