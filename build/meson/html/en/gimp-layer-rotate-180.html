7.50. Rotate 180°

The Rotate 180° command rotates the selected layers by 180° around the center of the layers, with no loss of pixel data.

The shape of the layer is not altered. Since the layers have a rectangular shape, a 180° rotation only inverts them and they can't extend beyond the image limits.

7.50.1. Activating the Command

You can access this command from the main menu through Layer → Transform → Rotate 180°.
