3.6. Copy

The Copy command makes a copy of the current selection and stores it in the Clipboard. The information can be recalled using Paste, Paste In Place, or one of the many Paste as commands. If there is no selection, the entire current layer is copied.

Note

The Copy command only works on the currently selected layers. All other layers are ignored.

3.6.1. Activating the Command

  • You can access this command from the main menu through Edit → Copy.

  • You can also use the keyboard shortcut Ctrl+C.
