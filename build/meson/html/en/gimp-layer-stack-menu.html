7.14. “Stack” Submenu

The layer stack is simply the list of layers in the Layers dialog. The Stack submenu contains operations which either allow you to change which layers are selected, or change the position of the selected layers in the layer stack. If your image has only one layer, these commands are disabled.

7.14.1. Activating the Submenu

You can access this submenu from the main menu through Layer → Stack.

7.14.2. The Contents of the “Stack” Submenu

The Stack submenu contains the following commands:

  • Section 7.15, “Select Previous Layers”

  • Section 7.16, “Select Next Layers”

  • Section 7.17, “Select Top Layer”

  • Section 7.18, “Select Bottom Layer”

  • Section 7.19, “Raise Layers”

  • Section 7.20, “Lower Layers”

  • Section 7.21, “Layers to Top”

  • Section 7.22, “Layers to Bottom”

  • Section 7.23, “Reverse Layer Order”
