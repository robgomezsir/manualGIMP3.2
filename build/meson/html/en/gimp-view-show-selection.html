5.20. Show Selection

The Show Selection command enables and disables displaying the dotted line surrounding the selection in the image window. Please note that the selection still exists, even if displaying this line is disabled.

You can set the default for displaying the selection in the Image Window Appearance Preferences.

5.20.1. Activating the Command

  • You can access this command from the main menu through View → Show Selection.

  • You can also use the keyboard shortcut Ctrl+T.
