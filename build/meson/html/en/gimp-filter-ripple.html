5.10. Ripple

5.10.1. Overview

Figure 17.80. “Ripple” filter example

Original image

Filter applied


It displaces the pixels of the active layer or selection to waves or ripples reminding a reflection on disturbed water.

5.10.2. Activating the Filter

This filter is found in the main menu under Filters → Distorts → Ripple….
