5. Other Tools

To access these tools, select Tools from the main menu.

5.1. Overview

“Other” tools are those tools which don't belong to any main group of tools.

This category includes the following tools:

  • Section 5.2, “Paths”

  • Section 5.3, “Text”

  • Section 5.4, “Color Picker”

  • Section 5.5, “Measure”

  • Section 5.6, “Zoom”
