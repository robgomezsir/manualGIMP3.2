4.3. None

The None command cancels all selections in the image. If there are no selections, the command doesn't do anything. Floating selections are not affected.

4.3.1. Activating the Command

  • You can access this command from the main menu through Select → None.

  • You can also use the keyboard shortcut Shift+Ctrl+A.

  • You can also access this command from the bottom bar of the Selection Editor, or through the Tab menu in the Selection Editor Menu.
