5.25. Show Sample Points

This command enables and disables showing the sample points in the image window. Sample points are used to display color information in the sample points dialog.

You can set the default for showing sample points in the Image Window Appearance Preferences.

5.25.1. Activating the Command

You can access this command from the main menu through View → Show Sample Points.
