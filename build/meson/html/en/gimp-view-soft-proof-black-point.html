5.17. Black Point Compensation

When enabled, Black Point Compensation will be used for the current display of the image.

Black Point Compensation is used to compensate for differences in black levels available on different devices. When enabled, it makes adjustments based on the differences between the color profile of the image and that of the output device, as represented by the soft-proof profile.

To get an idea how your image will look enable View → Color Management → Proof Colors.

5.17.1. Activating the Command

You can access this command from the main menu through View → Color Management → Black Point Compensation.
