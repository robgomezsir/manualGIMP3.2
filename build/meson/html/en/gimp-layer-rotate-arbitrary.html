7.51. Arbitrary Rotation

The Arbitrary Rotation command rotates the selected layers by a specified angle. It is an alternate way of accessing the Rotate tool. See the section about that tool for more information.

7.51.1. Activating the Command

  • You can access this command from the main menu through Layer → Transform → Arbitrary Rotation.

  • You can also use the keyboard shortcut Shift+R.
