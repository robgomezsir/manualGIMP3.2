7.39. Semi-Flatten

The Semi-Flatten… command is described in the Semi-Flatten filter chapter. The command is useful when you need an anti-aliased image with indexed colors and transparency.

Note

This command only works on a single layer.

7.39.1. Activating the Command

  • You can access this command from the main menu through Layer → Transparency → Semi-Flatten….

  • You can also access it from the main menu through Filters → Web → Semi-Flatten… (see Section 15.3, “Semi-Flatten”).
