10.2. Repeat Last

The Repeat Last command performs the action of the most recently executed plug-in again, using the same settings as the last time it was run. It does not show a dialog or request confirmation.

Note

Please note that this command repeats the most recently executed plug-in, regardless of whether it is in the Filters menu or not.

10.2.1. Activating the Command

  • You can access this command from the main menu through Filters → Repeat filter.

  • You can also use the keyboard shortcut Ctrl+F.
