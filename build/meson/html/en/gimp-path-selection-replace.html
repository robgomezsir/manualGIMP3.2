4.7. Selection From Paths

The Selection From Paths command transforms the selected paths into a selection. If a path is not closed, the command connects the two end points with a straight line. The original path is unchanged.

4.7.1. Activating the Command

  • You can access this command from the main menu through Select → Selection From Paths.

  • In addition, you can click on the Path to Selection button in the Paths dialog to access the command.

  • You can also use the keyboard shortcut Shift+V.
