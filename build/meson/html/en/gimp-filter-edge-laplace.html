8.4.1. Overview

Figure 17.173. Applying example for the Laplace filter

Original image

Filter applied


This filter detects edges in the image using Laplacian method, which produces thin, pixel wide borders.

8.4.2. Activating the Filter

This filter is found in the main menu under Filters → Edge-Detect → Laplace….
