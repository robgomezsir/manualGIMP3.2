13.12. Small Tiles

13.12.1. Overview

Figure 17.326. Example for the “Small Tiles” filter

Original image

Filter applied


This filter reduces the image (active layer or selection) and displays it in many copies inside the original image.

Note

If the image is in indexed mode, this menu entry is disabled.

13.12.2. Activating the Filter

This filter is found in the main menu under Filters → Map → Small Tiles….

13.12.3. Options

Figure 17.327. “Small Tiles” filter options


Flip

You can flip tiles according to the Horizontal or/and Vertical axis by checking the corresponding option(s).

You can also decide which tiles will be flipped:

All tiles

All tiles will be flipped.

Alternate tiles

Only odd tiles will be flipped.

Explicit tile

You can define a particular tile using both Row and Column input boxes. This tile will be marked with a box in Preview. Press Apply to mark this explicit tile. Repeat this procedure to mark more than one tile.

Opacity

With this slider and its input box, you can set the opacity of the resulting image. This option is valid only if your image has an Alpha channel.

Number of Segments

n² means “the image into n to the power of two tiles”, where “n” is the number you set with the slider or its input box. n = 3 will make nine tiles in the image.
