3.17. Fill Paths

This function fills all areas delimited by the selected paths.

This command is only enabled when at least one path is selected.

3.17.1. Activating the Command

You can access this command from the main menu through Edit → Fill Paths….

3.17.2. Options

This command brings up a dialog window:

Figure 16.11. The “Choose Fill Style” dialog


Foreground color

The foreground color of the toolbox is used.

Background color

The background color of the toolbox is used.

Pattern

The active pattern of the toolbox is used.

Antialiasing

This option is checked by default.
