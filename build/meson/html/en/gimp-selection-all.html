4.2. Select All

The Select All command creates a new selection which contains everything on the current layer.

4.2.1. Activating the Command

  • You can access this command from the main menu through Select → All.

  • You can also use the keyboard shortcut Ctrl+A.

  • You can also access this command from the bottom bar of the Selection Editor, or through the Tab menu in the Selection Editor Menu.
