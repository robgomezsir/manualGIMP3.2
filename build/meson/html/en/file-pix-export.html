5.40. Export Image as Alias Pix

5.40.1. Overview

You can export your image in Alias pix format when you choose the “.pix” extension, or explicitly choose “Alias Pix Image” as file type in the export dialog.

There are no settings to choose from. No export dialog will open after you have chosen your filename. It will automatically start the export.
