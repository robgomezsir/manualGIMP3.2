12.8. Slide

12.8.1. Overview

Figure 17.281. Example for the “Slide” filter

Original image

Filter applied


This filter makes your image look like a slide, by adding a slide-film like black frame, sprocket holes, and labels.

If necessary, the image will be cropped to fit into an aspect ratio of width : height = 3:2. If image width is greater than image height, black frames will be added at the top and the bottom of the image, else the frames will be added on the left and right sides. You may select the color as well as the font of the text appearing on the frames. The current background color will be used for drawing the holes.

Note

The filter only works on RGB and grayscale images without an alpha channel. Otherwise, the menu entry is disabled.

12.8.2. Activating the Filter

This filter is found in the main menu under Filters → Decor → Slide….

12.8.3. Options

Figure 17.282. “Slide” options


Text

A short label that will be displayed in the top (or the left) of the frame. The text must be really short.

Number

Here you may enter a text for simulating consecutive numbers. Two numbers will be displayed: this number and this number with the character “A” appended.

Font

Clicking on this button opens the Font dialog, where you can choose a font for the text on the frame.

Font color

Clicking on this button brings up a color selection dialog that allows you to choose the color of the text.

Work on copy

If checked, the filter creates a copy of the image with the filter applied. The original image remains unchanged.
