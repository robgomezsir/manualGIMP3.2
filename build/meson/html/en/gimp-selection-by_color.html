4.6. By Color

The By Color command is an alternate way of accessing the “Select By Color” tool, one of the basic selection tools. You can find more information about using this tool in Select By Color.

4.6.1. Activating the Command

  • You can access this command from the main menu through Select → By Color.

  • You can also use the keyboard shortcut Shift+O.
