7.27. Delete Layer Masks

The Delete Layer Masks command deletes the layer masks of the selected layers, without modifying the layers they belong to.

This menu command is disabled when none of the selected layers has a mask.

7.27.1. Activating the Command

  • You can access this command from the main menu through Layer → Mask → Delete Layer Masks.

  • From the Layers Dialog, you can access it through the Delete Layer Masks command of its context menu.
