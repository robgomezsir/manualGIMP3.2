5.29. Export Image as Microsoft Windows Icon

5.29.1. Overview

Figure 15.77. The Microsoft Windows Icon Export dialog


The Microsoft Windows Icon format is used on Windows for displaying icons. It supports multiple icon sizes and color depths.

A related format is the Microsoft Windows Cursor. The export dialog shows all the icons available. For each icon size, there are several settings that can be changed.

5.29.2. Options

Save type

For each icon size you can select in what format it should be saved. The available choices are:

1 bpp, 1-bit alpha, 2-slot palette

Indexed format with only two colors.

4 bpp, 1-bit alpha, 16-slot palette

Indexed format with only 16 colors.

8 bpp, 1-bit alpha, 256-slot palette

Indexed format with up to 256 colors.

24 bpp, 1-bit alpha, no palette

For RGB without alpha channel.

32 bpp, 8-bit alpha, no palette

The most common format is RGB with alpha channel.

Compressed (PNG)

When checked, the icons are saved as compressed PNG images. Note that not all programs support reading this type of icon.
