8.4. Hue Chroma

The Hue-Chroma filter is another way to modify saturation. Clear explanations about chroma and saturation can be found at https://ninedegreesbelow.com/photography/changing-saturation-using-lch-chroma.html .

8.4.1. Activating the Command

You can access this command from the main menu through Colors → Hue-Chroma….

8.4.2. Options

Figure 16.125. Hue-Chroma Options


Presets, Blending Options, Preview, Merge filter, Split view
Note

These options are described in Section 8.1.2, “Colors Common Features”.

Hue

The slider and the + and - buttons allow you to select a hue in the color wheel (-180°, 180°).

Chroma

“Chroma” is the purity of the color. Moving this slider makes colors more or less pure.

Lightness

This slider and the + and - buttons allow you to select a value (luminosity): -100, 100.
