7.38. Color to Alpha

The Color to Alpha… command makes all pixels with a specified color in the current layer transparent. For more details see Section 8.57, “Color to Alpha…”.

Note

This command only works on a single layer.

7.38.1. Activating the Command

  • You can access this command from the main menu through Layer → Transparency → Color to Alpha….

  • You can also access it from the main menu through Colors → Color to Alpha… (see Section 8.57, “Color to Alpha…”).
