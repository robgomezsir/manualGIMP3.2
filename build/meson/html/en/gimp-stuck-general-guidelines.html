2.16. General guidelines on what to check if you are stuck

  • Check the status bar to see if there is a message telling you what is happening.

    Tip

    If you add the Error Console to one of your docks most of the warnings will appear there. This can make it easier to spot any problems.

  • Check the Tool Options and make sure that all settings there have expected values, or else try to reset to default values.

  • Check which Image Mode your image is using. Some operations have limitations when using Indexed mode.

  • Check if a selection is active and if needed remove the selection.

  • Check the Layers Dialog and make sure the correct layer is active, that the opacity, blending mode and layer attributes are set as expected.

  • Check the View Menu to see if the part of the user interface that you are looking for is hidden, or to make sure that snapping is enabled or disabled as desired.
