5.9. Full Screen

The Fullscreen command enables and disables displaying the image window on the entire screen. When it is enabled, the image window takes up the whole screen, but the image stays the same size. When you enable full-screen mode, the menubar may not be displayed, but if this happens, you can right-click on the image to access the main menu. You can set the default appearance for full-screen mode in the Preferences menu.

Pressing the Tab key toggles the visibility of all present docks.

Note

If you use GIMP on an Apple computer, full-screen mode may not work, since Apple doesn't provide the necessary functionality. Instead, you can maximize the image window by clicking on the Green Button, so the image occupies most of the screen.

5.9.1. Activating the Command

  • You can access this command from the main menu through View → Full Screen.

  • You can also use the keyboard shortcut F11.

  • In multi-window mode, you can also get it by double-clicking on the title bar of the image window.
