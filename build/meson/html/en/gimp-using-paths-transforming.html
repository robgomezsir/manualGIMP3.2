4.4. Transforming Paths

Each of the Transform tools (Rotate, Scale, Perspective, etc) can be set to act on a layer, selection, or path. Select the transform tool in the toolbox, then select layer, selection, or path for the Transform option in the tool's Tool Options dialog. This gives you a powerful set of methods for altering the shapes of paths without affecting other elements of the image.

By default a Transform tool, when it is set to affect paths, acts only on the active path which is shown highlighted in the Paths Dialog. You can make a transformation affect more than one path by selecting additional paths. Selecting multiple paths is done by using the mouse and Shift key, for adding a range of paths, or Ctrl key, for adding or removing the clicked path.
