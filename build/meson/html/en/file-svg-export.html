5.50. Export Image as SVG

5.50.1. Overview

Figure 15.92. The SVG Export dialog


Scalable Vector Graphics (SVG) is a vector graphics format, allowing to export your image as vectors. Raster layers can be included too if desired.

5.50.2. Options

Embed raster layers as

Select how raster layers should be included.

PNG (always)

All raster layers will be included in the SVG as PNG images.

JPEG (for opaque images, PNG otherwise)

Raster layers will be included in the SVG as JPEG images when they are opaque, and as PNG when there is transparency.

Do not export raster layers

All raster layers will be ignored when exporting.
