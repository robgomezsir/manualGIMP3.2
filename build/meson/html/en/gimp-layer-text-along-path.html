7.13. Text along Path

This command wraps the text in the selected text layer along the currently active path. The active path can be changed through the Paths Dialog. For more information see also Text along Path in Text Management.

Note

This command only appears in the Layer menu if one text layer is selected. At least one path needs to be available, or this command will have no effect.

7.13.1. Activating the Command

  • You can access this command from the main menu through Layer → Text along Path.

  • From the Layers Dialog, you can access it through the Text along Path command of its context menu.
