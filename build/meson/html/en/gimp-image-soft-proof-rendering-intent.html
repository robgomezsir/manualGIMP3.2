6.15. Soft-Proofing Rendering Intent

The Soft-Proofing Rendering Intent lets you choose the rendering intent for the soft-proof profile. For more details about the available choices, see Rendering Intent .

Relative colorimetric is usually the best choice (default). Unless you use a LUT monitor profile (most monitor profiles are matrix), choosing perceptual intent actually gives you relative colorimetric.

To get an idea how your image will look with the soft-proof profile enable View → Color Management → Proof Colors.

6.15.1. Activating the Submenu

You can access this submenu from the main menu through Image → Color Management → Soft-Proofing Rendering Intent; then choose the option you prefer.
