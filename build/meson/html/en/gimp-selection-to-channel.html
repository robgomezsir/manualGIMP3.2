4.18. Save to Channel

The Save to Channel command saves the selection as a channel. The channel can then be used as a channel selection mask. You can find more information about them in the Channels Dialog section.

4.18.1. Activating the Command

  • You can access this command from the main menu through Select → Save to Channel.

  • You can also access this command from the bottom bar of the Selection Editor.
