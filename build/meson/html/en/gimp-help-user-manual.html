12.4. User Manual

Figure 16.237. The “User Manual” submenu of the Help menu


The User Manual command displays a submenu which lists links to several parts of the user manual. Clicking on one of them will open the desired user manual topic. Depending on your help preferences this will open either the local or online user manual, either in your browser or in GIMP's own help browser.
