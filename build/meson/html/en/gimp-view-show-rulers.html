5.34. Show Rulers

The Show Rulers command enables and disables displaying the rulers. It may be useful to disable them if you are working in full-screen mode.

You can set the default for the rulers in the Image Window Appearance Preferences.

5.34.1. Activating the Command

  • You can access this command from the main menu through View → Show Rulers.

  • You can also use the keyboard shortcut Shift+Ctrl+R.
