2.14. Export As…

The Export As… command allows you to store your image in a format other than XCF.

Note

Please refer to Section 1, “Files” for information about exporting in different file formats.

2.14.1. Activating the Command

  • You can access this command from the main menu through File → Export As….

  • You can also use the keyboard shortcut Shift+Ctrl+E.
