8.32. Sepia

8.32.1. Overview

Figure 16.182. Example for the “Sepia” filter

Original image

“Sepia” filter applied


The Sepia filter imitates sepia toning to produce a black-and-white picture with a warm brown-ish tone.

8.32.2. Activating the Command

You can access this command from the main menu through Colors → Desaturate → Sepia….

8.32.3. Options

Figure 16.183. “Sepia” options


Presets, Blending Options, Preview, Merge filter, Split view
Note

These options are described in Section 8.1.2, “Colors Common Features”.

Effect strength

This slider lets you control how much the effect blends into the original image. 0.000 is no effect at all, 1.000 is completely replacing the image with its sepia-toned version.

sRGB

This checkbox allows you processing the image in either sRGB gamma-corrected (checked) or linear (unchecked) color space.
