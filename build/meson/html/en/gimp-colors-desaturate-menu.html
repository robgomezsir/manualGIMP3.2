8.28. The “Desaturate” Submenu

The Desaturate submenu contains operations that turn an image into a Grayscale representation, using different methods.

  • Section 8.29, “Color to Gray”

  • Section 8.30, “Desaturate”

  • Section 8.24, “Mono Mixer”

  • Section 8.32, “Sepia”

8.28.1. Activating the Submenu

You can access this submenu from the main menu through Colors → Desaturate.
