2.13. Export… and Overwrite…

When the opened image is a native XCF file this command is called “Export”. In that case, it does the same thing as Export As….

When the opened image was imported, this command is called “Overwrite filename.extension”. Using this command, you can export the imported image directly in its original file format, without going through the export dialog.
