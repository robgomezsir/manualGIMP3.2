Bem-vindo à equipe de ajuda do GIMP!

Este tutorial se destina a escrever documentação. Se você quiser traduzir a documentação ou a interface do usuário, vá para "https://l10n.gnome.org/teams/xx" onde "xx" é o seu código de linguagem: ISO 639-1 códigos de idioma podem ser encontrados em https://www.loc.gov/standards/iso639-2/php/code_list.php.

1. Pré-requisitos

1.1. Junte-se ao Discourse

Você pode se juntar ao servidor do Discourse da Gnome e se inscrever para as etiquetas gimp e documentação. Por favor, sinta-se à vontade para fazer perguntas. Se você fizer, lembre-se de usar as etiquetas relevantes, ou podemos não ver a mensagem.

1.2. Criar uma cópia local de trabalho no código

O Manual de ajuda do GIMP está alojado em um repositório central em https://gitlab.gnome.org/GNOME/gimp-help. Criar uma cópia local deste repositório para trabalhar garante que todos possam trabalhar por conta própria, sem se confundir com os trabalhos de outros contribuidores.

Como um novato, você acessará o repositório git anonimamente (sem uma conta). Abra um terminal e digite: git clone https://gitlab.gnome.org/GNOME/gimp-help.git .

Se você tiver uma conta GNOME, o comando é: git clone git@gitlab.gnome.org:GNOME/gimp-help.git .

Isso criará uma pasta “gimp-help” em seu diretório atual. Seja paciente! É um grande download: cerca de 700 MB.

1.3. Instalando seu sandbox

Depois de realizar sua cópia local, execute: cd gimp-help então ./autogen.sh --without-gimp ALL_LINGUAS="en xx".

Ao executar ./autogen.sh, você pode notar alguns pacotes não encontrados, por exemplo “verificando por dblatex... não”. A maioria deles está relacionada a arquivos PDF e você deve instalá-los antes de executar o ./autogen.sh novamente se quiser criar arquivos PDF.

1.4. A pasta gimp-help

O Manual do Usuário GIMP é mantido nos arquivos xml da pasta “src”. Você usará esses arquivos xml para trabalhar.
