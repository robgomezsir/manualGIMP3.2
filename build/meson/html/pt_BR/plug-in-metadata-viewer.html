6.40. Metadata Viewer

This plug-in allows you to view all Exif, IPTC, and XMP metadata present in the current image. To change or add metadata, you can use the Metadata Editor.

Figura 16.89. “Metadata Viewer” dialog


6.40.1. Ativando o comando

You can access this command from the main menu through Image → Metadata → View Metadata.

6.40.2. “Metadata Viewer” Options

Each of the three metadata types is shown in its own tab. Check the links below for an explanation of what they are.

  • Exif: see Exif

  • XMP: see XMP

  • IPTC: see IPTC
