6.33. Nova guia

The New Guide… command adds a guide to the image.

Dica

Você pode adicionar novas guias de forma mais rápida, mas menos precisa, simplesmente clicando e arrastando guias a partir das réguas ao redor da imagem e posicionando-as onde desejar. Este comando é útil se você deseja uma posição precisa para a guia.

6.33.1. Ativando o comando

You can access this command from the main menu through Image → Guides → New Guide

6.33.2. Opções para “Nova guia”

Quando você seleciona Nova guia, se abre um diálogo que permite que você determine a Direção e a Posição, em pixels, da nova guia, de forma mais precisa do que clicando e arrastando.

Figura 16.80. O diálogo de “Nova guia”


Direção

Você pode escolher a Direção da guia, entre Horizontal e Vertical, usando a lista flutuante.

Posição

A coordenada de origem para a Posição é o canto superior esquerdo da tela de pintura.
