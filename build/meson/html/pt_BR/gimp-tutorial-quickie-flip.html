4.8. Espelhar uma Imagem

Use this option when you need the person in the photo looking in the other direction, or you need the top of the image to be the bottom. Select Tools → Transform Tools → Flip from the main menu, or use the button on the toolbox. After selecting the flip tool from the toolbox, click inside the canvas. Controls in the Tool Options dockable let you switch between Horizontal and Vertical modes.

Depois de selecionar a ferramenta Espelhar da caixa de ferramentas, clique dentro da tela. A ferramenta espelha a imagem horizontalmente. Use as opções de diálogo para alternar entre horizontal e vertical. Se ela não estiver sendo exibida no encaixe sob a caixa de ferramentas, clique duas vezes no botão de caixa de ferramentas. Você também pode usar a tecla Ctrl para alternar entre horizontal e vertical.
