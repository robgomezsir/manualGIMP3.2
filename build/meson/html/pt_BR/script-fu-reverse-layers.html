7.23. Reverse Layer Order

This command reverses the order of the layers. That is, the top layer becomes the bottom layer, and so on until the bottom layer becomes the top layer.

7.23.1. Ativando o comando

You can access this command from the main menu through Layers → Stack → Reverse Layer Order.
