8.28. O Submenu “Dessaturar”

O submenu Dessaturar contém operações que tornam uma imagem em uma representação em Tons de Cinza, usando diferentes métodos.

  • Seção 8.29, “Cor para Cinza”

  • Seção 8.30, “Dessaturar”

  • Seção 8.24, “Mono Mixer”

  • Seção 8.32, “Sépia”

8.28.1. Ativando o submenu

You can access this submenu from the main menu through Colors → Desaturate.
