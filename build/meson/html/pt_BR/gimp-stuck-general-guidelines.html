2.16. Diretrizes gerais sobre o que verificar se você estiver travado

  • Verifique a barra de status para ver se há uma mensagem dizendo o que está acontecendo.

    Dica

    Se você adicionar o Console de Erros a um dos seus docks, a maioria dos avisos aparecerá lá. Isso pode facilitar a identificação de problemas.

  • Verifique as Opções da Ferramenta e certifique-se de que todas as configurações lá tenham os valores esperados, ou tente redefinir para os valores padrão.

  • Verifique qual Modo de Imagem sua imagem está usando. Algumas operações têm limitações ao usar o Modo Indexado.

  • Verifique se uma seleção está ativa e, se necessário, remova a seleção.

  • Check the Layers Dialog and make sure the correct layer is active, that the opacity, blending mode and layer attributes are set as expected.

  • Check the View Menu to see if the part of the user interface that you are looking for is hidden, or to make sure that snapping is enabled or disabled as desired.
