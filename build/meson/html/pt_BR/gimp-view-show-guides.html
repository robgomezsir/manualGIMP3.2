5.23. Exibir as guias

O comando Exibir as guias ativa e desativa a exibição das Guias no menu da janela de imagem.

You can set the default for the guides in the Image Window Appearance Preferences.

5.23.1. Ativando o comando

  • You can access this command from the main menu through View → Show Guides.

  • You can also use the keyboard shortcut Shift+Ctrl+T.
