3.9. Desfoque Variável

3.9.1. Visão geral

Figura 17.29. O filtro Desfoque Variável

Imagem original

Filter applied


Variable Blur blurs the image by a variable amount using a mask set in Input. Black in the mask layer will be minimally blurred, and white will be blurred at maximum value.

3.9.2. Ativando o filtro

This filter is found in the main menu under Filters → Blur → Variable Blur….

3.9.3. Opções

Figura 17.30. Opções do diálogo do filtro Desfoque Variável


Presets, “Input Type”, Clipping, Blending Options, Preview, Merge filter, Split view
Nota

Essas opções são descritas em Seção 2, “Recursos comuns”.
Input

Aqui, você pode definir a máscara que determina o quanto uma certa área da camada selecionada estará desfocada. Áreas pretas na máscara resultarão em borrão mínimo na saída, e brancas estarão borradas ao máximo.

Raio

Raio máximo do desfoque.

Máscara linear

Se habilitado, usar valores de máscara lineares.

Alta qualidade

Se habilitado, gera uma saída mais precisa e consistente ao custo de ser mais devagar.
