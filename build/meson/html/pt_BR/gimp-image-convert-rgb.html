6.4. Modo RGB

O comando RGB converte sua imagem para o modo RGB. Veja a descrição de RGB no glossário para maiores informações. Normalmente, você trabalhará neste modo, que é bem adaptado à tela. É possível converter uma imagem RGB para o modo de Tons de cinza ou Indexado, mas seja cuidadoso: a não ser desfazendo este comando, você não poderá mais recuperar as cores RGB originais da sua imagem. Então é melhor fazer essa conversão sempre numa cópia da imagem.

6.4.1. Ativando o comando

You can access this command from the main menu through Image → Mode → RGB.
