2.14. Exportar para

Exportar como... permite que você salve a sua imagem em um formato diferente do XCF.

Nota

Consulte Seção 1, “Arquivos” para obter informações sobre como exportar uma imagem para diferentes formatos de arquivo.

2.14.1. Ativando o comando

  • You can access this command from the main menu through File → Export As….

  • You can also use the keyboard shortcut Shift+Ctrl+E.
