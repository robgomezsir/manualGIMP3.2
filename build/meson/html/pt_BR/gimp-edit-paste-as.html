3.10. Colar como

This command pastes the clipboard contents. Of course, you must use the “Copy” command before, so that you have something in the clipboard.

There is no way to empty the clipboard.

The submenu offers several ways to paste the clipboard contents:

  • Seção 3.10.1, “Paste as Single Layer”

  • Seção 3.10.2, “Paste As Single Layer In Place”

  • Seção 3.10.3, “Colar como Nova imagem”

  • Seção 3.10.4, “Paste as Floating Data”

  • Seção 3.10.5, “Paste as Floating Data In Place”

  • Seção 3.10.6, “Paste as Floating Data Into Selection”

  • Seção 3.10.7, “Paste as Floating Data Into Selection In Place”

  • Seção 3.10.8, “Colar como Novo pincel”

  • Seção 3.10.9, “Colar como Nova textura”

3.10.1. Paste as Single Layer

The Paste as Single Layer command creates a new layer in the active image and pastes the clipboard contents into it.

If the data are not rectangular or square in shape, any regions that do not extend to the edge of the canvas are left transparent (an Alpha channel is automatically created). Of course, you have to copy your selection before you use this command.

3.10.1.1. Ativando o comando

You can access this command from the main menu through Edit → Paste as → Paste as Single Layer.

3.10.2. Paste As Single Layer In Place

The Paste as Single Layer In Place command creates a new layer in the active image and pastes the clipboard contents at the exact coordinates the contents was originally copied from.

Esse recurso está disponível tanto para a área de transferência comum quanto para buffers nomeados.

3.10.2.1. Ativando o comando

You can access this command from the main menu through Edit → Paste as → Paste as Single Layer In Place.

3.10.3. Colar como Nova imagem

O comando Colar como nova imagem cria uma nova imagem e cola o conteúdo da área de transferência na mesma. Se o conteúdo não tiver forma retangular ou quadrada, as áreas faltantes são deixadas como transparentes (o canal alfa é criado automaticamente). A nova imagem tem o mesmo tamanho que a seleção.

Este comando tem exatamente a mesma ação que o comando Arquivo → Criar → Da área de transferência.

3.10.3.1. Ativando o comando

  • You can access this command from the main menu through Edit → Paste as → Paste as New Image.

  • You can also use the keyboard shortcut Shift+Ctrl+V.

3.10.4. Paste as Floating Data

The Paste as Floating Data command creates a floating selection in the active image and pastes the clipboard contents into it.

If the data are not rectangular or square in shape, any regions that do not extend to the edge of the canvas are left transparent (an Alpha channel is automatically created). Of course, you have to copy your selection before you use this command.

Nota

Você só pode ter uma seleção flutuante ativa de cada vez. Você não pode realizar alterações em outras camadas se houver uma seleção flutuante; você precisa ancorar, descartar ou transformar a seleção flutuante em uma nova camada antes de continuar trabalhando no restante da imagem.
3.10.4.1. Ativando o comando

You can access this command from the main menu through Edit → Paste as → Paste as Floating Data.

The Paste as Floating Data In Place command creates a floating selection in the active image and pastes the clipboard contents into it at the exact coordinates the contents was originally copied from.

If the data are not rectangular or square in shape, any regions that do not extend to the edge of the canvas are left transparent (an Alpha channel is automatically created). Of course, you have to copy your selection before you use this command.

Você só pode ter uma seleção flutuante ativa de cada vez. Você não pode realizar alterações em outras camadas se houver uma seleção flutuante; você precisa ancorar, descartar ou transformar a seleção flutuante em uma nova camada antes de continuar trabalhando no restante da imagem.
3.10.5.1. Ativando o comando

3.10.6. Paste as Floating Data Into Selection

The Paste as Floating Data Into Selection command replaces the contents of the current selection with the contents of the clipboard and turns it into a floating selection.

The clipboard data is clipped by the selection, but the image data in it can still be moved if it extends outside the selection.

If no selection exists, the “Paste as Floating Data Into Selection” command places the data from the clipboard into the center of the canvas, as the “Paste” command does.

Nota

Você só pode ter uma seleção flutuante ativa de cada vez. Você não pode realizar alterações em outras camadas se houver uma seleção flutuante; você precisa ancorar, descartar ou transformar a seleção flutuante em uma nova camada antes de continuar trabalhando no restante da imagem.
3.10.6.1. Ativando o comando

You can access this command from the main menu through Edit → Paste as → Paste as Floating Data Into Selection.

3.10.7. Paste as Floating Data Into Selection In Place

The Paste as Floating Data Into Selection In Place command replaces the contents of the current selection with the contents of the clipboard, at the exact coordinates the contents was originally copied from, and turns it into a floating selection.

The clipboard data is clipped by the selection, but the image data in it can still be moved if it extends outside the selection.

If no selection exists, the “Paste as Floating Data Into Selection In Place” command places the data from the clipboard into the center of the canvas, as the “Paste” command does.

Nota

Você só pode ter uma seleção flutuante ativa de cada vez. Você não pode realizar alterações em outras camadas se houver uma seleção flutuante; você precisa ancorar, descartar ou transformar a seleção flutuante em uma nova camada antes de continuar trabalhando no restante da imagem.
3.10.7.1. Ativando o comando

You can access this command from the main menu through Edit → Paste as → Paste as Floating Data Into Selection In Place.

3.10.8. Colar como Novo pincel

Este comando abre uma janela de diálogo que permite que você dê um nome ao seu novo pincel. O pincel aparece no Diálogo de pincéis. Se a imagem de onde você copiou o conteúdo for em Tons de cinza, o novo pincel usará a cor ativa na Caixa de ferramentas quando você o usar.

3.10.8.1. Opções

Figura 16.8. The “New Brush” dialog


Nome do pincel

Brush name is the name that will be shown in the “Brushes” Dialog.

Nome do arquivo

O novo pincel é salvo com o nome digitado em Nome do arquivo (com a extensão .gbr) na sua pasta pessoal de pincéis do GIMP (brushes)

Espaçamento

Espaçamento: Quando o pincel desenha uma linha, na verdade ele é “carimbado” repetidas vezes na imagem. Se as imagens do pincel carimbadas dessa forma estiverem muito próximas uma das outras, você terá a impressão de uma linha contínua.

3.10.8.2. Ativando o comando

You can access this command from the main menu through Edit → Paste as → Paste as New Brush….

3.10.9. Colar como Nova textura

Este comando abre uma janela de diálogo que permite que você de um nome para a sua nova textura. A textura aparece no Diálogo de texturas.

3.10.9.1. Opções

Figura 16.9. The “New Pattern” dialog


Nome da textura

Pattern name is the name that will be shown in the “Patterns” Dialog.

Nome do arquivo

A nova textura é salva como Nome do arquivo (com a extensão .pat) na sua pasta pessoal de texturas do GIMP (patterns)

3.10.9.2. Ativando o comando

You can access this command from the main menu through Edit → Paste as → Paste as New Pattern….
