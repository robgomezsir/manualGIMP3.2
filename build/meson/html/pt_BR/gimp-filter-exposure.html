8.7. Exposição

Este filtro é usado para clarear sombras e tons médios de uma imagem sem estourar os tons claros. Um tutorial detalhado pode ser encontrado em Apêndice C, Mapeamento de tons e Recuperação de sombras usando os recursos do GIMP: Cores → Exposição.

8.7.1. Ativando o comando

You can access this command from the main menu through Colors → Exposure….

8.7.2. Opções

Figura 16.129. Opções de Exposição


Predefinições, Opções de Mistura, Preview, Merge filter, Split view
Nota

These options are described in Seção 8.1.2, “Funcionalidades Comuns de Cores”.

Nível de preto

Esta opção é usada para dispensar as informações "inúteis" de sombras e tons claros.

Exposição

Esta opção é usada para adicionar uma ou mais paradas de compensação de exposição à imagem.
