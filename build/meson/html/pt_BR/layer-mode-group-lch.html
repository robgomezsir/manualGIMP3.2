2.7. Modos de Camada de Componentes LCh

O grupo “LCh” contém modos de camada que fazem uso do modelo de cor LCh. “LCh” significa Clareza, Croma, Matiz. É derivado matematicamente do espaço de cor de referência CIELAB. Veja também CIELCh.

Matiz LCh

Figura 8.41. Exemplo para modo de camadas “Matiz”

Camada superior em 100% de opacidade usando o modo “Matiz LCh”.


O modo Matiz LCh corresponde ao Matiz HSV, mas é baseado em diferentes fórmulas matemáticas.

Croma LCh

Figura 8.42. Exemplo para o modo de camada “Normal”

Camada superior em 100% de opacidade usando o modo “Croma LCh”.


O modo Croma LCh corresponde à Saturação HSV, mas é baseado em diferentes fórmulas matemáticas.

Cor

Figura 8.43. Exemplo para o modo de camada “Cor”

Camada superior em 100% de opacidade usando o modo “Cor LCh”.


LCh Color mode is a combination of LCh Chroma and LCh Hue, and corresponds to HSV Color, but is based on different mathematical formulas. See A tutorial on GIMP's very awesome LCH Blend Modes for information on using this layer mode.

Clareza LCh

Figura 8.44. Exemplo para modo de camadas “Somente clarear”

Camada superior em 100% de opacidade usando o modo “Clareza LCh”.


LCh Lightness mode corresponds to HSV Value, but is based on different mathematical formulas. See A tutorial on GIMP's very awesome LCH Blend Modes for information on using this layer mode.

Luminância

Figura 8.45. Exemplo para modo de camadas “Matiz”

Camada superior em 100% de opacidade usando o modo “Luminância”.


O modo Luminância é semelhante à luminância CIE, mas não altera a saturação. Ele divide a luminância da camada superior pela luminância da camada inferior; então usa esse resultado para multiplicar com o componente da camada inferior.
