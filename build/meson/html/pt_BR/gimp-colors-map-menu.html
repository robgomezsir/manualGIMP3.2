8.33. O submenu “Mapear”

O submenu Mapear contém operações que lhe permitem mapear as cores de uma imagem para cores diferentes de várias formas.

  • Seção 8.34, “Rearranja o mapa de cores”

  • Seção 8.35, “Especifica o mapa de cores”

  • Seção 8.36, “Mapeamento alien”

  • Seção 8.37, “Troca de cores”

  • Seção 8.38, “Rotaciona cores”

  • Seção 8.39, “Mapear com degradê”

  • Seção 8.40, “Mapear com paleta”

  • Seção 8.41, “Colorizar a partir de amostra”

8.33.1. Ativando o submenu

You can access this submenu from the main menu through Colors → Map.
