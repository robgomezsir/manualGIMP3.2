2.3. Imagens

Você também deve gerenciar as capturas de tela. Aqui estão algumas dicas para fazer boas capturas de tela:

  • reduza a área de captura de tela o máximo possível cortando as bordas do gerenciador de janelas e desabilitando o botão de ajuda (você pode fazer isso na caixa de diálogo de preferências),

  • defina o modo de imagem para Indexado com 255 cores Imagem → Modo → Indexado

    Isso não é necessário para ícones e se sua imagem tiver apenas algumas cores. Nestes casos, as imagens indexadas são maiores do que as não indexadas.

  • defina a resolução de impressão para 144 ppp (não para imagens pequenas como ícones). Você pode fazer isso facilmente com o GIMP em Imagem → Tamanho de impressão

  • Exporte imagens no formato PNG.

Não inclua texto em inglês nas imagens. Os tradutores não podem traduzi-lo e muitos usuários não gostam disso. Em vez disso, use legendas em XML ou forneça um arquivo .xcf na pasta Docs → xcf images, indicando isso com um comentário no arquivo XML: <!--TO TRANSLATORS: Corresponding .xcf file is in https://gitlab.gnome.org/GNOME/gimp-help/tree/master/docs/xcf%20images -->

Os ícones do GIMP estão em /usr/share/gimp/3.0/icons/. Os ícones do GTK estão em /usr/share/icons/.

Para incluir um ícone no texto: <guiicon> <inlinemediaobject> <imageobject> <imagedata fileref="path-to-icon"/> </imageobject> </inlinemediaobject> </guiicon>

Três comandos para gerenciar suas imagens:

  • make check-image-resolutions-en: fornece as referências de imagens cuja resolução não é 144 ppp.

  • make check-images-en: dá referências de imagens perdidas ou órfãs.

  • mogrify units PixelsPerTrack -density 144x144 *.png para definir a resolução de impressão de todas as imagens PNG.
