3. O menu “Editar”
 

3.22. Atalhos de teclado

This command opens the Keyboard Shortcuts Dialog. Using that dialog you can add or change keyboard shortcuts to menu commands, tools, filters etc. A quicker way to change shortcuts to menu commands is described in Seção 2, “Criando atalhos para funções nos menus”.

3.22.1. Ativando o comando

You can access this command from the main menu through Edit → Keyboard Shortcuts.
