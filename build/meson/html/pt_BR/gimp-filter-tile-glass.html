11.5. Glass Tile

11.5.1. Visão-geral

Figura 17.217. The same image, before and after applying glass tile effect.

Imagem original

Filter applied


After applying this filter, the active layer or selection is rendered as through a glass brick wall.

11.5.2. Activating the Filter

This filter is found in the main menu under Filters → Artistic → Glass Tile….

11.5.3. Opções

Figura 17.218. “Glass Tile” filter options


Presets, “Input Type”, Clipping, Blending Options, Pré-visuação, Merge filter, Split view
Nota

Essas opções são descritas em Seção 2, “Recursos comuns”.
Tile width, Tile height

Sets tile width and length (10-50 pixels).

By default, width and height are linked, indicated by the chain symbol next to the input boxes. If you want to set width and height separately, click on that chain symbol to unlink them.
