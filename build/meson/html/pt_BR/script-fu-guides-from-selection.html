6.34. Novas guias a partir da seleção

O comando Novas guias a partir da seleção adiciona quatro linhas guia, uma para cada um dos limites da seleção atual - em cima, em baixo, direita e esquerda. Se não houver uma seleção na imagem atual, nenhuma guia é desenhada.

6.34.1. Ativando o comando

You can access this command from the main menu through Image → Guides → New Guides from Selection.
