2.13. Exportar… e sobrescrever…

Este comando é chamado “ Exportar para ” para um arquivo XCF nativa. Em seguida, ele faz a mesma coisa que Exportação .

O nome do comando se torna “Sobrescrever nome.extensão” para uma imagem que foi importada. Assim, você pode exportar a imagem importada diretamente em seu formato de arquivo original, sem passar pelo diálogo de exportação.
