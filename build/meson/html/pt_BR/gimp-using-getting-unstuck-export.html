4. Como corrigir problemas ao exportar imagens

4.1. Estou exportando para uma imagem jpeg e minha área transparente ficou branca ou preta

Ao exportar imagens, você precisa estar ciente de que a maioria dos formatos de imagem tem limitações. Uma limitação das imagens jpeg é que elas não suportam transparência. Ao exportar para jpeg, o GIMP preenche as áreas transparentes com a cor de fundo, que por padrão é branca.

Para corrigir isso, você terá que escolher um formato de imagem diferente que suporte transparência, como png ou tiff.
