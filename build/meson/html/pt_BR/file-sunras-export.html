5.49.1. Visão geral

Figura 15.91. The SUN Rasterfile Export dialog


Sun Raster was a raster graphics file format used on SunOS by Sun Microsystems. This format does not support transparency.

5.49.2. Opções

Data formatting

This setting allows you to choose whether the image should be stored as Standard (uncompressed data), or as Run-Length Encoding (compressed data). The latter should in general produce smaller files.
