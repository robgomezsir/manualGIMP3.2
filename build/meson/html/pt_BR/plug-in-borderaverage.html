8.52. Média da borda

8.52.1. Visão geral

Figura 16.211. Exemplo do filtro “Média da borda”

Imagem original

Foreground color in the Toolbox after applying the “Border Average” filter


This plug-in calculates the most often used color in a specified border of the active layer or selection. It can gather similar colors together so that they become predominant. The calculated color becomes the foreground color in the Toolbox. This filter is interesting when you have to find a Web page color background that differs as little as possible from your image border. The action of this filter is not registered in Undo History and can't be undone with Ctrl+Z: it doesn't modify the image.

Nota

Este comando somente funciona em imagens RGB. Se a imagem estiver em Tons de Cinza ou for Indexada, a entrada no menu é desativada.

8.52.2. Activating the Command

You can access this command from the main menu through Colors → Info → Border Average….

8.52.3. Opções

Figura 16.212. Options of the “Border Average” filter


Tamanho da borda

The border Thickness in pixels.

Número de cores

O Tamanho de Balde lhe permite controlar o número de cores que serão consideradas como similares e contadas no mesmo “balde” (faixa de cores no histograma). Um tamanho de balde pequeno (ou seja, um grande número de baldes distintos) dá uma melhor precisão no cálculo da média de cor. Note que uma melhor precisão não significa necessariamente um melhor resultado (veja o exemplo abaixo).

8.52.4. Exemplos ilustrando o filtro “Média da Borda”

Figura 16.213. Imagem original

Original image: colors are pure Red (255;0;0), pure Blue (0;0;255), and different but similar kinds of Green (0;255;0 , 63;240;63 , 48;224;47 , 0;192;38).


Figura 16.214. O “Número de cores” está definido como 8:

A cor resultante é Vermelho (254,2,2).


The bucket size is low. So the bucket number is high. All color shades can be stored in different buckets. Here, the bucket containing red is the most filled. The resulting color is a nearly pure Red (254,2,2) and becomes the foreground color in the Toolbox.

Figura 16.215. O “Número de cores” está definido como 64:

A cor resultante é Verde (32,224,32).


Neste caso o tamanho do balde é grande, então o número de baldes é pequeno. Cores similares (neste caso, verde) estão armazenadas no mesmo balde. Agora este balde “verde” é o mais cheio. Todas as cores neste balde tem os mesmos valores para os dois bits mais importantes: (00******;11******;00******). Os 6 bits restantes podem ter qualquer valor de 0 a 63 para o respectivo canal. Então, neste balde, os canais de cor vermelha vão de 0 a 63, canais de verde vão de 192 a 255, canais de azul vão de 0 a 63. A cor resultante é Verde (32,224,32), o que, para cada canal, é a média entre os limites do intervalo do canal (63 + 0)/2, (255+192)/2, (63+0)/2.
