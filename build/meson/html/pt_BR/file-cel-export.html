5.10. Export Image as KiSS CEL

5.10.1. Visão geral

You can export your image in cel format, which is short for “KiSS cel” format, when you choose the “.cel” extension, or explicitly choose “KISS CEL” as file type in the export dialog. This file format is used to create and display digital dress-up paper dolls.

There are no settings to choose from. No export dialog will open after you have chosen your filename. It will automatically start the export.
