8.34. Rearranja o mapa de cores

Figura 16.184. A janela “Rearranja o mapa de cores”


This command allows you to re-organize colors in the palette of indexed images. It doesn't modify the image. You can't add or remove colors; for that, see The Indexed Palette Dialog.

Nota

If your image is not indexed, this command is disabled.

8.34.1. Activating the Command

  • You can access this command from the main menu through Colors → Map → Rearrange Colormap….

  • You can also access it from the Colormap Dialog using the right-click context menu Rearrange Colormap….

8.34.2. Usando o diálogo “Rearranja o mapa de cores”

You can drag and drop colors using the mouse to rearrange the colormap. You can sort colors based on Hue, Saturation and Value by using the buttons. You can also reverse or reset the order of the colors.

Dica

Another way to sort a colormap is by using the Sort Palette… context menu command available in the Palettes Dialog.
