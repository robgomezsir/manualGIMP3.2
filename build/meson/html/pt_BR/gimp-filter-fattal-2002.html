8.43. Fattal et al. 2002

8.43.1. Visão geral

Figura 16.198. Exemplo de mapeamento de tons “Fattal et al. 2002”

Imagem original

Filtro aplicado com configurações padrão, após alteração da precisão da imagem no GIMP para ponto flutuante de 32 bit por luz linear.


Este filtro pode ser usado para adaptar uma imagem, que pode ter um alto intervalo dinâmico (HDR), para apresentação usando um baixo intervalo dinâmico. Esta operação reduz as magnitudes de gradientes de imagem locais, produzindo luminância no intervalo 0,0-1,0.

Esta abordagem de mapeamento de tons foi originalmente apresentada por Raanan Fattal, no artigo publicado em 2002 na SIGGRAPH: Gradient Domain High Dynamic Range Compression.

Nota

Este filtro é lento em imagens grandes. Para encontrar as melhores configurações para sua imagem, você poderia fazer uma pequena seleção relevante primeiro e salvá-la como pré-configuração antes de usá-la para a imagem completa.

8.43.2. Activating the Command

You can access this command from the main menu through Colors → Tone Mapping → Fattal et al. 2002….
