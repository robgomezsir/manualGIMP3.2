2.5. Enviando seus arquivos

Quando seus arquivos estiverem prontos:

Você não tem uma conta GNOME

se você não tem uma conta GNOME, você deve encontrar um correspondente que aceite "enviar" arquivos para você; isso não será difícil se você enviar uma mensagem para a lista. Ou você envia seus arquivos xml e as imagens anexadas em um arquivo compactado, (em uma árvore reproduzindo a das pastas src e de imagens se você enviar vários arquivos para tornar a tarefa do seu correspondente mais fácil), ou você envia uma "correção" (patch) que você tem que criar.

Antes de criar uma correção, você deve obter todos os seus arquivos xml e imagens no índice. Estando na pasta gimp-help, faça git status. Se você tiver arquivos na seção Arquivos não rastreados, execute git add -A.

Então execute git diff --full-index --binary origine > nome-do-patch para criar a correção.

Você tem uma conta GNOME

Estando tudo bem, você sabe administrar o Git. Existem muitos tutoriais para isso na web.

Um fluxo de trabalho comum é:

- make validate-en

- git status

- git stash

- git pull

- git status

- git stash apply

- Corrija eventuais conflitos

- git add -A

- git status

- git commit -m "alguma mensagem"

- git push
