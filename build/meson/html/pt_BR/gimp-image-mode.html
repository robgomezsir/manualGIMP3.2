6.3. “Mode” Submenu

O submenu Modo contém comandos que permitem que você altere o modo de cor da imagem. Atualmente há três modos.

6.3.1. Ativando o submenu

You can access this submenu from the main menu through Image → Mode.

6.3.2. O conteúdo do submenu “Modo”

  • RGB

  • Tons de cinza

  • Indexado
