8.51. Exportar Histograma

8.51.1. Visão geral

Exporta o Histograma da imagem para um arquivo de texto para que possa ser utilizado por outros programas e carregado em planilhas. O Histograma é produzido para a área da imagem selecionada. Pixels totalmente transparentes não são contados.

O arquivo resultante é um arquivo CSV (Valores Separados por Vírgula), que pode ser importado diretamente pela maioria dos programas de manipulação de planilhas. A primeira linha do arquivo CSV é uma linha de títulos. Uma linha de dados é gerada para cada "Balde". Cada valor de pixel pode estar no intervalo de 0 a 255, e será incluído em um dos baldes dependendo do intervalo do balde.

A primeira coluna é intitulada "Início do Intervalo" e contém o valor inicial do balde. As colunas seguintes contêm os valores para diferentes canais. Quais canais serão incluídos depende do tipo de imagem. O significado desses valores em cada uma das colunas de canais depende da opção Formato de Saída.

Figura 16.209. Exemplo do arquivo exportado com “Exportar Histograma” 

Início do intervalo,   Valor,   Vermelho,   Verde,   Azul
                  0,     0.0,        0.0,   486.0,    0.0
                  1,     0.0,        0.0,   300.0,    0.0
                  2,     0.0,        0.0,   336.0,    0.0
                  3,     0.0,        0.0,   399.0,    0.0
                  4,     0.0,        0.0,   510.0,    0.0
                  ....

O arquivo de exemplo acima foi gerado para uma imagem RGB, usando o formato de saída Contagem de pixels, e um Tamanho de Balde de 1. A linha iniciada pelo número 3 descreve o quarto balde e incluirá todos os pixels de valor 3 até (sem incluir) 4. O número 399.0 naquela linha pode então ser interpretado como "Há 399 pixels que apresentam um valor de Verde de 3".

8.51.2. Activating the Command

You can access this command from the main menu through Colors → Info → Export Histogram….

8.51.3. Opções

Figura 16.210. “Export Histogram” options


Arquivo do Histograma

O arquivo para o qual o histograma será exportado.

Tamanho de Balde

O Tamanho de Balde permite controlar o número de valores considerados similares e contados no mesmo “balde” (faixa de cores no histograma). Um tamanho de balde maior produzirá menos baldes, e portanto menos linhas no arquivo exportado. Por exemplo, um Tamanho de Balde de 1 produzirá 256 baldes, enquanto um Tamanho de 16 produzirá 16 baldes.

Amostra da média

Se Amostra da média estiver ativa, o histograma será gerado para uma imagem obtida pela combinação de todas as camadas visíveis. Se não, o histograma considerará somente a camada atual.

Output format

Se a opção Contagem de pixels for escolhida, os valores no arquivo gerado refletirão a quantidade de pixels em cada balde. Se Normalizado for escolhida, os valores serão a quantidade de pixels no balde dividida pelo total de pixels. A opção Porcentagem é similar à Normalizado, mas os valores são formatados como porcentagens.
