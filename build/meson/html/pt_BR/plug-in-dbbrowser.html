12.10. O navegador de procedimentos

O comando Navegador de procedimentosmostrará os procedimentos disponíveis na PDB, a base de dados de procedimentos. Esses procedimentos possuem funções que são chamadas por scripts ou plug-ins.

12.10.1. Acessando o comando

You can access this command from the main menu through Help → Procedure Browser.

12.10.2. Descrição da janela de “Navegador de procedimentos”

Figura 16.242. A janela de “Navegador de procedimentos”


A figura abaixo mostra a janela de Navegador de procedimentos. Se você clicar em um dos itens da lista da caixa esquerda, então as informações sobre este item serão mostradas no lado direito. Você também pode buscar por um procedimento em especifico da base de dados procedural usando uma expressão em especial através da caixa de texto Procurar:

por nome

Shows a list of procedures which have code names that contain the part of the name you entered.

por descrição

Mostra uma lista de procedimentos que possuem, entre as suas notas, a palavra digitada.

por ajuda

Shows a list of procedures which have additional information text that contains the word you entered.

by authors

Shows a list of procedures created by the author whose name contains the word you entered.

por copyright

Shows a list of procedures whose copyright are hold by someone whose name contains the word you entered.

por data

Shows a list of procedures which have a date of a year which matches the year you entered.

Nota

Este tipo de pesquisa funciona com o texto e não com o valor da data em si, então você não conseguirá encontrar alguns procedimentos mesmo que eles sejam do ano que você está procurando. Por exemplo, um procedimento com data 2000-2005 não irá aparecer caso você busque por 2001, mas irá aparecer se você buscar por 2000 ou 2005.
por tipo

Shows a list of procedures which have one of four types: “Internal GIMP procedure”, “GIMP Plug-In ”, “GIMP Extension”, or “Temporary Procedure”.
