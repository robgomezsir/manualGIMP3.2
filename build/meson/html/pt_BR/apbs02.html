2. Fluxo de trabalho

2.1. Escrita

O idioma é o Inglês (EUA).

Para editar arquivos XML, use seu editor de texto preferido (o autor deste guia prefere o editor gratuito Kate). Você deve definir o editor para:

  • Idioma inglês-americano.

  • Recue com 2 espaços (a tecla Tab deve mover o ponteiro em dois espaços).

  • Substitua tabulações por espaços (para compatibilidade com todos os editores de texto e navegadores da web).

  • 80 caracteres por linha.

  • Verificação ortográfica automática com inglês (EUA) para o idioma padrão.

Os arquivos-fonte são gravados na linguagem XML de acordo com o DocBook DTD. As especificações do DocBook podem ser encontradas em https://tdg.docbook.org/tdg/4.5/docbook.html.

Não tenha medo. Não usamos todos esses itens e você aprenderá XML progressivamente lendo arquivos XML existentes. Para novos arquivos, use os modelos que você pode encontrar na pasta gimp-help/docs/templates.

Nota

Se você escrever um novo arquivo, deverá adicioná-lo ao arquivo src/gimp.xml, ou ao arquivo XML que o chama (por exemplo, o arquivo src/menus/edit.xml chama undo.xml, redo.xml, fade.xml, e assim por diante).
