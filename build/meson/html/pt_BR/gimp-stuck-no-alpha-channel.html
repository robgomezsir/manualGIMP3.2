2.12. A borracha não torna a área transparente

Como saber: Você está tentando usar a borracha para remover toda a cor, mas em vez de uma área transparente aparecer, ela se torna a cor de fundo (geralmente branca).

Como corrigir: Verifique a camada ativa na caixa de diálogo Camadas: clique com o botão direito nela para abrir um menu e veja se Adicionar Canal Alfa está habilitado. Se estiver, sua camada não tem canal alfa: clique naquele item de menu para adicionar um canal alfa. Com isso corrigido, você poderá apagar até a transparência.
