6.3.2. Opções

Política de Depuração

A Política de Depuração diz ao GIMP o que você quer fazer se o GIMP encontrar um problema. Você tem quatro opções:

Depurar avisos, erros críticos e falhas

Esta é a opção mais intrusiva. Geralmente usada apenas quando tentando encontrar um bug específico. Isso inicia o depurador para qualquer tipo de falha, erro ou aviso.

Depurar erros críticos e falhas

Iniciar depuração quando o GIMP encontrar uma falha ou um erro crítico.

Depurar apenas falhas

Iniciar depuração apenas quando o GIMP encontrar uma falha.

Nunca depurar o GIMP

Não importa o que aconteça, o depurador nunca será iniciado.

Depuração eficaz só é possível se você tiver o gdb ou lldb instalado.
