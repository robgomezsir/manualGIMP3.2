8.46. Stress

8.46.1. Visão geral

Figura 16.204. Exemplo de mapeamento de tons por “Stress”

Imagem original

Filtro aplicado com configurações padrão, após alteração da precisão da imagem no GIMP para ponto flutuante de 32 bit por luz linear.

Filtro aplicado com Amostras em 15 e Iterações em 20.


Este filtro usa um Envelope Espaço-Temporal tipo Retinex com Amostragem Estocástica (STRESS). Os algoritmos funcionam pelo recálculo de cada pixel usando envelopes para os limites superior e inferior locais na imagem. Os envelopes são obtidos por amostragem dos pixels vizinhos e podem ser interpretados como máximo e mínimo de referência local. Este método pode ser usado para esticamento de contraste local, correção automática de cor, renderização de imagem com alto intervalo dinâmico, mapeamento espacial de gama de cor, e conversão de cor para tons de cinza com bons resultados.

Based on Ø. Kolås, I. Farup, and A. Rizzi, “Spatio-temporal retinex-inspired envelope with stochastic sampling: A framework for spatial color algorithms”, Journal of Imaging Science and Technology, vol. 55, no. 4, pp. 1–10, 2011.

Nota

Este filtro é lento em imagens grandes. Para encontrar as melhores configurações para sua imagem, você poderia fazer uma pequena seleção relevante primeiro e salvá-la como pré-configuração antes de usá-la para a imagem completa.

8.46.2. Activating the Command

You can access this command from the main menu through Colors → Tone Mapping → Stress….

8.46.3. Opções

Figura 16.205. O diálogo do filtro “Stress”


Pré-configurações, Input Type, Clipping, Blending Options, Preview, Merge filter, Split view
Nota

These options are described in Seção 8.1.2, “Funcionalidades Comuns de Cores”.

Raio

Vizinhança a ser considerada. Para aprimoramento, os valores ideais são próximos ao maior lado da imagem (pode ser tanto a largura quanto a altura). Aumentar este valor torna o filtro mais lento.

Amostras

Número de amostras a realizar por iteração buscando o intervalo de cores.

Iterações

Número de iterações: um número maior de iterações gera uma renderização com menos ruído, mas torna o filtro mais lento.

Melhorar sombras

Quando ativado, regiões de sombra também são melhoradas; quando desativado, um resultado mais natural é obtido.
