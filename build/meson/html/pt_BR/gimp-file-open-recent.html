2.8. Abrir recente

Selecionando Abrir recente, você vê um submenu com os nomes dos arquivos que você abriu recentemente no GIMP. Basta clicar em um nome para reabri-lo. Veja o diálogo de Histórico de documentos na parte inferior do submenu Abrir recente, se você não consegue encontrar a sua imagem na lista.

2.8.1. Ativando o comando

You can access this command from the main menu through File → Open Recent.
