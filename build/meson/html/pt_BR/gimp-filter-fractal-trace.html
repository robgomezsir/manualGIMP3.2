13.4. Traçar com fractal

13.4.1. Visão geral

Figura 17.299. Traçar com fractal

Imagem original

Filter applied


Este filtro transforma a imagem com o fractal de Mandelbrot: ele mapeia a imagem para o fractal.

13.4.2. Activating the Filter

This filter is found in the main menu under Filters → Map → Fractal trace….

13.4.3. Opções

Figura 17.300. Opções do filtro “Traçar com fractal”


Opções

Presets, “Input Type”, Clipping, Blending Options, Pré-visualização, Merge filter, Split view
Nota

Essas opções são descritas em Seção 2, “Recursos comuns”.
Fractal type

You choose between “Mandelbrot” and “Julia”.

X1, X2, Y1, Y2, Profundidade

These parameters are similar to Left, Right, Top, Bottom and Iterations parameters of the Fractal Explorer filter. They allow you to vary fractal spreading and detail depth.

JX, JY

Julia seed X and Y value positions. Only shown when fractal type is Julia.

Bailout length

Abyss policy

Mapping image to fractal may reveal empty areas. These options allows you to set displacement behavior on active layer or selection edges. They are described in Abyss policy
