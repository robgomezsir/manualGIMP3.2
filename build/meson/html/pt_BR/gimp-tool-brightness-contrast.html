8.9. Brilho-Contraste

A ferramenta Brilho-Contraste ajusta os níveis de brilho e contraste para a camada ou seleção ativa. Esta ferramenta é fácil de usar, mas relativamente não-sofisticada. As ferramentas Níveis e Curvas lhe permitem fazer os mesmos tipos de ajustes, mas também lhe dão a habilidade de tratar cores brilhantes diferentemente das cores mais escuras. Em termos gerais, a ferramenta Brilho-Contraste é ótima para um ajuste "rápido e grosseiro" em poucos segundos, mas se a imagem é importante e você quer que ela pareça tão boa quanto possível, você vai querer usar uma das outras ferramentas.

Dica

Além de usar os controles deslizantes, você também pode ajustar as configurações clicando com o mouse dentro da imagem e arrastando enquanto o botão esquerdo do mouse estiver pressionado. Mover o mouse verticalmente altera o brilho; mover horizontalmente muda o contraste. Quando você estiver satisfeito com o resultado, você pode ou apertar o botão OK no diálogo, ou apertar a tecla Enter.

8.9.1. Ativando o comando

  • You can access this command from the main menu through Colors → Brightness-Contrast….

  • You can also access it by clicking the tool icon in the Toolbox if this tool has been installed there. For this, please refer to Seção 6.13, “Caixa de ferramentas”.

8.9.2. Opções

Nota

These options are described in Seção 8.1.2, “Funcionalidades Comuns de Cores”.

Brilho

Este controle deslizante define um valor negativo (para escurecer) ou positivo (para clarear) para o brilho, diminuindo ou aumentando tons claros.

Contraste

Este controle deslizante define um valor negativo (para diminuir) ou positivo (para aumentar) para o contraste.

Edite estas configurações como Níveis

Para facilitar seu trabalho, este botão lhe permite alternar para a ferramenta Níveis com as mesmas configurações.
