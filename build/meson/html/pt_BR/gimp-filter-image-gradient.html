This filter detects edges in one or two gradient directions.

8.7.2. Activating the Filter

This filter is found in the main menu under Filters → Edge-Detect → Image Gradient….

8.7.3. Opções

Figura 17.180. Image Gradient filter options


Presets, “Input Type”, Clipping, Blending Options, Pré-visualização, Merge filter, Split view
Nota

Essas opções são descritas em Seção 2, “Recursos comuns”.
Output mode

Magnitude is default: it combines both directions. Direction: only one direction is used. Both is like Magnitude.
