5.24. Export Image as Header

5.24.1. Visão geral

Exporting your image as a C header file happens when you choose the “.h” extension, or explicitly choose “C source code header” as file type in the export dialog.

There are no settings to choose from. No export dialog will open after you have chosen your filename. It will automatically start the export.
