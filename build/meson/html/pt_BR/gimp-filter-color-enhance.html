8.20. Equilíbrio de Cores

O comando Equilíbrio de Cores estica o intervalo de Croma das cores na camada ao máximo possível, sem alterar Matiz e Luminosidade. Isto é feito convertendo-se os valores para o espaço de cores CIE LCh, e então esticando-se o intervalo de Croma para ser tão largo quanto possível, e finalmente convertendo-se as cores de volta ao seu espaço de cores nativo.

Nota

Este comando não funciona em imagens em Tons de Cinza. Se a imagem estiver em Tons de Cinza, a entrada do menu estará desativada.

8.20.1. Ativando o comando

You can access this command from the main menu through Colors → Auto → Color Enhance.
