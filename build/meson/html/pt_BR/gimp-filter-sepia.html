8.32.1. Visão geral

Figura 16.182. Exemplo para o filtro “Sépia”

Imagem original

Filtro “Sépia” aplicado


O filtro Sépia imita a tonalidade sépia para produzir uma figura em preto-e-branco com uma tonalidade quente amarronzada.

8.32.2. Ativando o Comando

You can access this command from the main menu through Colors → Desaturate → Sepia….

8.32.3. Opções

Figura 16.183. Opções de “sépia”


Pré-configurações, Blending Options, Preview, Merge filter, Split view
Nota

These options are described in Seção 8.1.2, “Funcionalidades Comuns de Cores”.

Força do efeito

Este seletor deslizante lhe permite controlar em quanto o efeito se mistura à imagem original. 0,000 representa efeito nenhum, 1,000 é a substituição completa da imagem pela sua versão em tons de sépia.

sRGB

Esta opção lhe permite processar a imagem no espaço de cores sRGB, ou corrigido pela gama (selecionada) ou linear (não selecionada).
