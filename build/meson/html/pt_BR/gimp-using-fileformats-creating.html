2. Criando novos arquivos

Use Arquivo → Nova para abrir o dialogo Criar uma nova imagem. Modifique a largura e altura iniciais da imagem ou use os valores padrão, em seguida, crie uma nova imagem. Mais informações sobre o diálogo Criar uma nova imagem podem ser encontradas em Seção 2.2, “Nova…”.
