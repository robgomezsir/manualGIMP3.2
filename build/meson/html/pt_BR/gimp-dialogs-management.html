4. Diálogos relacionados a gerenciamento de imagens

4.1. Diálogo de buffers

Figura 15.47. O diálogo de buffers, como uma lista


Buffers são um tipo de armazenamento temporário para dados de imagem, criados quando você recorta ou copia parte de um drawable (uma camada, máscara de camada, etc.). Os seguintes comandos estão disponíveis no menu Editar para salvar uma imagem em um buffer:

Cortar com nome

Editar → Buffer → Cortar Nomeado… Este comando recorta a parte selecionada do drawable atual (geralmente uma camada) e a coloca em um buffer. Se não houver seleção, todo o drawable será usado. Será solicitado que você dê um nome ao buffer. A imagem será removida da seleção depois disso.

Copiar com nome

Editar → Buffer → Copiar Nomeado… Este comando copia a parte selecionada do drawable atual (geralmente uma camada) e a coloca em um buffer. Se não houver seleção, todo o drawable será usado. Será solicitado que você dê um nome ao buffer.

Copiar com nome

Editar → Buffer → Copiar Visível Nomeado… Este comando copia a parte selecionada de todos os drawables visíveis e a coloca em um buffer. Se não houver seleção, toda a imagem será usada. Será solicitado que você dê um nome ao buffer.

Colar com nome

Editar → Buffer → Colar Nomeado… Este comando de menu abre a Caixa de Diálogo de Buffers. Para colar um buffer de fato, escolha um dos botões desta caixa de diálogo, ou o menu de contexto. Ambos serão explicados abaixo.

O diálogo de “Buffers” exibe o conteúdo de todos os buffers existentes, e permite que você trabalhe com eles de várias formas. Ele também mostra, no topo, o conteúdo do Buffer global (o que é usado para simplesmente copiar e colar), mas você não pode fazer nada com ele: só pode ver a miniatura de seus coteúdos.

Cuidado

Buffers com nome não são salvos entre sessões do GIMP. A única forma de salvá-los é colá-los em imagens.

4.1.1. Ativando o diálogo

O diálogo de “Buffers” é um diálogo de encaixe;veja a seção Seção 2.3, “Caixas de diálogo e de encaixe” para mais informações sobre como gerenciá-lo.

Você pode acessa-lo:

  • Do menu da janela de imagem, em Cores → Informação → Histograma.

  • Do menu da janela de imagens em Janelas → Diálogos de encaixe → Buffers.

  • from the Tab menu in any dockable dialog by clicking the tab menu button and selecting Add Tab → Buffers.

In the Windows menu, there is a list of detached windows which exists only if at least one dialog remains open. In this case, you can raise the “Buffers” dialog from the main menu: Windows → Buffers.

4.1.2. Usando o diálogo de buffers

Clique em um buffer na área principal do diálogo para torná-lo o buffer ativo, isto é, o que será usado para comandos de “Colar” realizados a partir do menu de contexto, ou dos botões na parte de baixo do diálogo. Um click duplo em um buffer faz com que seu conteúdo seja colado na imagem ativa como uma seleção flutuante; Esta é uma forma rápida de executar o comando “Colar buffer”

Na parte de baixo do diálogo há quatro botões. As ações dos mesmos também podem ser acessadas através do menu de Buffers, que você pode acessar pressionando o botão direito do mouse no diálogo.

Figura 15.48. O diálogo de Buffers (visão em grade)


No menu de Guia para o diálogo de “Buffers”, você pode escolher entre Ver como gradee Ver como lista. No modode grade, as miniaturas dos buffers aparecem em um arranjo regularde ícones. Apenas o nome do buffer selecionado é exibido. No modo de Lista, eles são alinhados um abaixo do outro,e o nome e tamanho em pixels de cada buffer são exibidos.

Dica

Ctrl+F abre uma caixa para pesquisas por nome. Para maiores informações sobre o modo de lista, veja View as List.

Você pode alterar o tamanho das pré-visualizações dos buffers, usando o submenu “Tamanho da pré-visualização” no menu de guia do diálogo.

4.1.2.1. Botões na parte de baixo

The button bar at the bottom offers the following functionality:

Colar buffer , Colar buffer em

Este comando cola o conteúdo do buffer selecionado na imagem ativa, como uma seleção flutuante. A única diferença entre esse comando e o Colar normal é que ele usa o buffer selecionado em vez do buffer global da área de transferência.

Com a tecla Shift pressionada, ele cola o buffer em sua localização original.

Colar buffer em , Colar Buffer na Seleção no Local

Este comando cola o conteúdo do buffer atual dentro da seleção da imagem ativa. A única diferença entre esse comando e o Colar em normal é que ele usa o buffer selecionado em vez do buffer global da área de transferência.

Com a tecla Shift pressionada, ele cola o buffer na seleção ativa em sua localização original.

Colar buffer como nova , Colar buffer como nova

Este comando cria uma nova imagem, de uma única camada, com o conteúdo do buffer selecionado. A única diferença entre esse comando e o Colar como nova normal é que ele usa o buffer selecionado em vez do buffer global da área de transferência.

Com a tecla Shift pressionada, ele cria a camada na localização original do buffer.

Colar buffer como nova

Este comando cria uma nova imagem, de uma única camada, com o conteúdo do buffer selecionado. A única diferença entre esse comando e o Colar como nova normal é que ele usa o buffer selecionado em vez do buffer global da área de transferência.

Remover buffer

Este comando apaga o buffer selecionado, sem perguntar nada. Você não pode apagar o Buffer global.
