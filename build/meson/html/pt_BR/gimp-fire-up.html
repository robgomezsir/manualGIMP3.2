1. Executando o GIMP

Geralmente, você inicia o GIMP clicando no ícone do GIMP na área de trabalho (se disponível), selecionando-o em um menu ou digitando gimp na linha de comando. Se houver várias versões do GIMP instaladas, talvez seja necessário informar o número exato da versão: gimp-3.2.

Se quiser, você pode informar na linha de comando, após o nome do programa, uma lista de arquivos de imagem para que o GIMP os abra automaticamente ao iniciar. Também é possível abrir arquivos pelo próprio GIMP depois que ele estiver em execução, usando o diálogo Abrir imagem.

A maioria dos sistemas operacionais oferece suporte a associações de arquivos, que vinculam uma classe de arquivos (definida pela extensão do nome, como .jpg) a um aplicativo correspondente (como o GIMP). Quando os arquivos de imagem estão corretamente “associados” ao GIMP, basta clicar duas vezes em uma imagem no gerenciador de arquivos para abri-la no GIMP.

Se você instalou a versão Flatpak do GIMP pelo flathub.org, inicie o GIMP clicando em um ícone ou digitando flatpak run org.gimp.GIMP//stable na linha de comando.

1.1. Alterar o idioma

O GIMP detecta e usa automaticamente o idioma do sistema. Se, excepcionalmente, a detecção falhar ou você quiser usar outro idioma, a maneira mais fácil é alterar o idioma nas Preferências da interface: acesse Editar → Preferências e abra a seção Interface; a opção Idioma fica no início da página.

Se preferir alterar o idioma definindo variáveis de ambiente, use as instruções a seguir:

No Linux

No Linux: no terminal, digite LANGUAGE=en gimp ou LANG=en gimp, substituindo en por fr, de etc., conforme o idioma desejado. Ao usar LANGUAGE=en, você define uma variável de ambiente para o programa gimp executado.

No Windows

Na área “Variáveis do sistema”, acesse Painel de Controle → Sistema → Avançado → Ambiente e clique em Adicionar. Informe LANG como nome e fr, de etc. como valor. Atenção: é preciso clicar em OK três vezes seguidas para confirmar a alteração.

Se você troca de idioma com frequência, pode criar um arquivo de lote para fazer a alteração. Abra o Bloco de Notas e digite os comandos a seguir (para francês, por exemplo):

set lang=fr
start gimp-3.2.exe

Salve o arquivo como GIMP-FR.BAT (ou com outro nome, mas sempre usando a extensão .BAT). Crie um atalho e arraste-o para a área de trabalho.

No macOS da Apple

Em Configurações do Sistema, clique em General na barra lateral. Em seguida, selecione Idioma e Região. O idioma desejado deve ser o primeiro da lista.

Outra instância do GIMP

Você pode usar o parâmetro de linha de comando -n para executar várias instâncias do GIMP. Por exemplo, gimp-3.2 inicia o GIMP no idioma padrão do sistema, enquanto LANGUAGE=en gimp-3.2 -n inicia outra instância do GIMP em inglês. Isso pode ser muito útil para tradutores.

1.2. Argumentos da Linha de Comando

Embora não seja necessário usar argumentos de linha de comando para iniciar o GIMP, eles podem ser úteis em algumas situações. Em sistemas Unix, use man gimp para consultar a lista completa.

Adicione esses argumentos à linha de comando usada para iniciar o GIMP, no formato gimp-3.2 [OPTION...] [FILE|URI...], em que “OPTION...” pode corresponder a um ou mais argumentos da lista abaixo, seguidos de um ou mais nomes de arquivos.

-?, -h, --help

Exibe a lista de todas as opções de linha de comando.

--help-all

Exibe todas as opções de ajuda, inclusive as do GEGL e do GTK.

--help-gegl

Exibe todas as opções do GEGL.

--help-gtk

Exibe as opções do GTK.

-v, --version

Imprime a versão do GIMP e sai.

--license

Mostrar informações de licença e sai.

--verbose

Mostrar as mensagens de inicialização em detalhes.

-n, --new-instance

Iniciar uma nova instância do GIMP.

-a, --as-new

Abre as imagens como se fossem novas.

-i, --no-interface

Executa sem uma interface de usuário, por exemplo, para se executar um script automaticamente, junto com a função --batch

-d, --no-data

Não carrega padrões, degradês, paletas ou pincéis. Essa opção é usada com frequência no modo não interativo para reduzir o tempo de inicialização.

-f, --no-fonts

Não carrega nenhuma fonte (tipográfica). Isso é útil para carregar o GIMP mais rápido para os scripts que não utilizam fontes, ou para encontrar problemas relacionados a fontes com problemas que possam fazer o GIMP travar.

-s, --no-splash

Não mostra a tela inicial durante a inicialização.

--no-shm

Não usa memória compartilhada entre o GIMP e os plug-ins.

--no-cpu-accel

Não use funções especiais de aceleração de CPU. Útil para encontrar ou desativar bugs das funções aceleradas em hardware.

--session=nome

Usa um arquivo sessionrc diferente nesta sessão do GIMP. O nome informado para a sessão é acrescentado ao nome padrão do arquivo sessionrc.

-g, --gimprc=nome-do-arquivo

Usa um arquivo gimprc alternativo em vez do arquivo padrão. O arquivo gimprc registra suas preferências. Isso é útil quando os caminhos dos plug-ins ou as especificações do computador são diferentes.

--system-gimprc=Nome do arquivo

Usa um arquivo gimprc de sistema alternativo.

-b, --batch=comandos

Executa o conjunto de comandos sem interação. Normalmente, esses comandos são fornecidos na forma de um script que pode ser executado por um dos interpretadores de scripts do GIMP. Quando o comando é -, os comandos são lidos da entrada padrão.

--batch-interpreter=proc

Especificar o procedimento a usar para processar os comandos de lote. O procedimento padrão é o Script-Fu.

--quit

Encerra imediatamente após executar as ações solicitadas.

-c, --console-messages

Não exibe caixas de diálogo quando ocorrem erros ou avisos; em vez disso, mostra as mensagens no console.

--pdb-compat-mode=modo

Modo de compatibilidade do PDB. Os modos são "off", "on", "warn" (desligado, ligado, aviso). O padrão é "aviso".

--stack-trace-mode=modo

Depurar no caso de uma falha. Os modos são "never", "query", "always" (nunca, consultar, sempre)

--debug-handlers

Habilita manipuladores de sinais de depuração não-fatais. Útil para depuração do GIMP.

--g-fatal-warnings

Trata todos os avisos como erros fatais. Útil para depuração.

--dump-gimprc

Imprime um arquivo gimprc com as configurações padrão. Útil se você estragou o seu arquivo gimprc.

--show-playground

Exibe uma página de preferências com recursos experimentais.

--show-debug-menu

Exibe um submenu Depuração no menu Arquivo, com comandos úteis para depurar o GIMP.

--display=display

Use o display X designado (não se aplica a todas as plataformas).

1.3. Pasta de configuração

Na primeira execução, o GIMP cria uma pasta de configuração, onde armazena todas as informações de configuração. Se você remover ou renomear essa pasta, o GIMP repetirá o processo de configuração inicial e criará uma nova pasta.

O local exato da pasta de configuração depende do seu sistema operacional:

No Linux:

$XDG_CONFIG_HOME

Geralmente: $HOME/.config/GIMP/3.2/

No Microsoft Windows, usando variáveis de ambiente:

%APPDATA%\GIMP\3.2\

Geralmente: %USERPROFILE%\AppData\Roaming\GIMP\3.2\

No macOS da Apple:

NSApplicationSupportDirectory

Geralmente: ~/Library/Application Support/GIMP/3.2/

1.4. Dicas e truques

Algumas sugestões antes de começar:

  • O GIMP oferece dicas que você pode consultar a qualquer momento pelo comando de menu Ajuda → Dica do dia. Elas trazem informações úteis que nem sempre são fáceis de descobrir por tentativa e erro, por isso vale a pena lê-las. Quando tiver tempo, consulte essas dicas.

  • Se, ao tentar fazer algo, o GIMP parecer parar de funcionar de repente, a seção Destravando o GIMP pode ajudar.

  • Não deixe de conferir o diálogo de preferências. O GIMP permite muitas personalizações, com diversas configurações que você pode ajustar às suas preferências.
