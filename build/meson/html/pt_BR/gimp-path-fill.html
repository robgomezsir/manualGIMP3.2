3.17. Fill Paths

This function fills all areas delimited by the selected paths.

This command is only enabled when at least one path is selected.

3.17.1. Ativando o comando

You can access this command from the main menu through Edit → Fill Paths….

3.17.2. Opções

Esse comando faz aparecer uma janela de diálogo:

Figura 16.11. A janela de diálogo “Escolher estilo de preenchimento”


Foreground color

A cor de frente da caixa de ferramentas é usada.

Background color

The background color of the toolbox is used.

Textura

A textura ativa da caixa de ferramentas é usada.

Anti-serrilhamento

Esta opção fica marcada por padrão.
