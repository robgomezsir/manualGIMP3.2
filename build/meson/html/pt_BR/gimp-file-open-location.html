2.7. Abrir URL

This command opens the “Open Location” dialog, which lets you load an image from an online or network location, specified by a URI, in any of the formats that GIMP supports.

2.7.1. Ativando o comando

You can access this command from the main menu through File → Open Location….

2.7.2. Descrição da janela de diálogo

Os esquemas mais comuns para abrir imagens são:

file://

para abrir uma imagem a partir de um arquivo em uma unidade local

Você pode omitir o prefixo “file://” e abrir imagens simplesmente colocando um caminho e o nome de arquivo absoluto ou relativo aqui.

A pasta padrão de base para caminhos relativos depende do seu sistema operacional. No Linux é tipicamente /home/<nome-do-usuário>/, no Windows, C:\Documents and Settings\<nome-do-usuário>\Meus Documentos\Minhas Imagens\ e /Users/<nome-do-usuário>/ no Mac OS X.

ftp://

para abrir uma imagem a partir de um servidor de ftp

https://, http://

para carregar uma imagem diretamente de um site web

Dica

Quando você está visitando um site na Internet, você pode clicar com o botão direito em uma imagem e escolher “Copiar URL da imagem” no menu flutuante. Em seguida, cole o link no diálogo de “Abrir URL” abrir a imagem no GIMP.

Mesmo que com este comando seja muito fácil pegar imagens de sites: favor respeitar os direitos autorais! Imagens, mesmo se publicadas na Internet, nem sempre são de uso livre para quaisquer fins.. Você pode usar qualquer imagem para fins pessoais, mas se for publicar de volta na internet, mesmo que seja em um perfil privado de redes sociais, a imagem tem que conceder direitos de modificação e redistribuição (como por exemplo, é dado pelas licenças Creative Commons)
