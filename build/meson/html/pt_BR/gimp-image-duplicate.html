6.2. Duplicar

O comando Duplicar cria uma nova imagem que é uma cópia exata da imagem atual, com todas as suas camadas, canais e caminhos. A área de transferência do GIMP e o Histórico de imagens não são alterados.

Nota

Não confunda uma imagem duplicada com uma nova visualização desta mesma imagem. Em uma Visualizar → Nova visualização, todas as modificações são refletidas na imagem original.

6.2.1. Ativando o comando

  • You can access this command from the main menu through Image → Duplicate.

  • You can also use the keyboard shortcut Ctrl+D.
