8.60. Quente…

8.60.1. Visão geral

Este comando identifica e modifica pixels que poderiam causar problemas quando exibidos em uma tela de TV PAL ou NTSC.

8.60.2. Ativando o comando

You can access this command from the main menu through Colors → Hot….

Nota

Este comando só funciona em imagens no modo RGB, e somente se a camada ativa não tiver um canal alfa. Se não, o comando será desabilitado.

8.60.3. Opções

Figura 16.232. Opções do “Quente”


Modo

You have to select the TV mode: PAL or NTSC.

Ação

Aqui você pode selecionar o método usado para remover os pixels quentes.

Reduzir Luminância, Reduzir Saturação

Blacken

This changes hot pixels to black.

Create new layer

Com esta opção marcada, o trabalho será feito em uma nova camada, em vez de na camada ativa.
