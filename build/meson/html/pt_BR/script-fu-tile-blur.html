3.13. Desfoque de Mosaico

3.13.1. Visão geral

Figura 17.37. Exemplo para o filtro “Desfoque de Mosaico”

Imagem original

Filter applied


O Desfoque de Mosaico na verdade é reproduzido por um script de Script-Fu que invoca o plug-in de desfocagem gaussiana.

Este filtro é utilizado para suavizar as emendas em imagens usadas para compor planos de fundo em mosaico. Isto é feito pela mistura e desfoque dos limites entre as imagens que estarão vizinhas após a composição do mosaico.

Dica

Se você deseja tratar apenas bordas das imagens, então você não pode aplicar o filtro em toda a imagem. A solução para obter o efeito desejado é a seguinte:

  1. Duplicate layer (Layer → Duplicate Layers) and select it to work on it.

  2. Aplique o filtro “Desfoque de Mosaico” com um raio de 20 pixels a essa camada.

  3. Selecione tudo (Ctrl+A) e reduza a seleção (Seleção → Encolher) para criar uma borda com a largura desejada.

  4. Dê uma borda enevoada à seleção usando Seleção → Enevoar.

  5. Delete a seleção com Ctrl+K.

  6. Combine as camadas com Camada → Combinar abaixo.
Nota

If the image is in grayscale mode or indexed mode, this menu entry is disabled.

3.13.2. Ativando o filtro

This filter is found in the main menu under Filters → Blur → Tileable Blur….
