2.4. Criar arquivos HTML

Assim que os arquivos XML forem validados, execute make html-en. Criar arquivos HTML é importante para se ter uma ideia do que os usuários verão. Você provavelmente notará algumas melhorias a serem feitas em seu arquivo XML.

Você pode fazer um rascunho de HTML (quando a pasta xml/en foi criada durante a validação) para um único arquivo xml de origem, executando, por exemplo, o comando make preview-xml/en/path-to-file.xml. Isso cria o arquivo draft.html na pasta html.

Você também pode usar yelp e executar yelp file:///seu-arquivo.xml.
