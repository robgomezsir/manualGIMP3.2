2.20. Close View

The Close View command closes the active image. It is disabled if no image is open.

Não é possível desfazer o fechamento de uma imagem: depois de fechá-la, tudo é perdido, inclusive o histórico de desfazer. Se a imagem não estiver “limpa” — isto é, se você a tiver alterado desde a última vez em que a salvou —, será solicitado que confirme se realmente deseja fechá-la.

Nota

Uma imagem só é marcada como limpa quando é salva como arquivo XCF. Exportá-la para outro formato de imagem não marca como limpa uma imagem alterada, pois a exportação não preserva todas as informações da imagem.

2.20.1. Ativando o comando

  • You can access this command from the main menu through File → Close View.

  • You can also use the keyboard shortcut Ctrl+W.

  • In single-window mode, you can also execute it by clicking the “Close” button on the image bar. In multi-window mode, you click the “Close” button on the image window.

    If the image has unsaved changes you will be asked whether you want to close it, possibly losing changes, or go back to working in GIMP so you can save the image.
