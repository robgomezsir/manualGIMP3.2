8.5. Neon

8.5.1. Visão-geral

Figura 17.175. Exemplo aplicativo para o filtro neon

Imagem original

Filter applied


Este filtro detecta bordas na camada ativa ou seleção e dá a eles um efeito de brilho de neon.

8.5.2. Activating the Filter

This filter is found in the main menu under Filters → Edge-Detect → Neon….

8.5.3. Opções

Figura 17.176. Opções do filtro neon


Presets, “Input Type”, Clipping, Blending Options, Pré-visualização, Merge filter, Split view
Nota

Essas opções são descritas em Seção 2, “Recursos comuns”.
Raio

Essa opção permite determinar o qual será a largura da borda detectada.

Intensity

Essa opção permite determinar a força do efeito do filtro.
