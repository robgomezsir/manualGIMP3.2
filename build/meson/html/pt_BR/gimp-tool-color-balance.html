8.2. Equilíbrio de Cores

A ferramenta de equilíbrio de cores modifica o equilíbrio das cores da camada ou seleção ativa. As mudanças não são drásticas. Esta ferramenta é apropriada para corrigir cores predominantes em fotos digitais.

Nota

Este comando não funciona em imagens em Tons de Cinza. Se a imagem estiver em Tons de Cinza, a entrada do menu é desativada.

8.2.1. Ativando o comando

You can access this command from the main menu through Colors → Color Balance….

8.2.2. Opções

Figura 16.122. Opções de Equilíbrio de Cores


Predefinições, Opções de Mistura, Preview, Merge filter, Split view
Nota

These options are described in Seção 8.1.2, “Funcionalidades Comuns de Cores”.

Select Range to Adjust

Selecting one of these options restricts the range of colors which are changed with the sliders or input boxes for Shadows (darkest pixels), Midtones (medium pixels) and Highlights (brightest pixels).

Adjust Color Levels

Sliders and range from the three RGB colors to their complementary colors (CMY). The zero position corresponds to the current level value of pixels in the original image. You can change the pixel color either towards Red or Cyan, Green or Magenta, Blue or Yellow.

Reiniciar Intervalo

Este botão define os níveis de cor para o intervalo selecionado de volta à posição zero (valores originais).

Preserve luminosity

Esta opção garante que o brilho da camada ou seleção ativa seja mantido. O Valor dos pixels mais claros não é alterado.
