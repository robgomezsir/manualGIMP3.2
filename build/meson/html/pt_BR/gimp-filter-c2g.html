8.29. Cor para Cinza

Esta conversão de cor para tons de cinza usa envelopes formados com a tal da abordagem STRESS para realizar a geração de tons de cinza com preservação da diferença local.

8.29.1. Ativando o Comando

You can access this command from the main menu through Colors → Desaturate → Color to Gray….

8.29.2. Opções

Figura 16.179. Configurações de “Cor para Cinza”


Pré-configurações, Input Type, Clipping, Blending Options, Preview, Merge filter, Split view
Nota

These options are described in Seção 8.1.2, “Funcionalidades Comuns de Cores”.

Raio

Vizinhança levada em conta, este é o raio em pixels considerado ao decidir quais cores mapear para quais valores de cinza.

Amostras

Número de amostras a retirar por iteração ao procurar pelo intervalo de cores.

Iterações

Número de iterações, um número maior providencia resultados com menos ruído ao custo de processamento.

Melhorar Sombras

Quando ativado, detalhes em sombras são aumentados ao custo de ruído.
