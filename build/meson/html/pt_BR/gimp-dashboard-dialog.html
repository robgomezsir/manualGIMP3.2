7.6. Painel de Controle

O Painel de Controle ajuda a monitorar o uso de recursos do GIMP (Cache, Swap, CPU, Memória). Isso permite que você tome decisões mais informadas sobre várias opções de configuração, especialmente Recursos do Sistema. Também é usado por desenvolvedores.

Figura 15.138. A “janela d e diálogo” terminal de erros


7.6.1. Ativando o diálogo

O diálogo de “Buffers” é um diálogo de encaixe;veja a seção Seção 2.3, “Caixas de diálogo e de encaixe” para mais informações sobre como gerenciá-lo.

Você pode acessa-lo:

  • from the main menu: Windows → Dockable Dialogs → Dashboard;

  • from the Tab menu in any dockable dialog by clicking the tab menu button and selecting Add Tab → Dashboard.

7.6.2. Usando o diálogo de vetores

O Painel de Controle consiste em cinco grupos que você pode monitorar: uso de Cache, uso de Swap, uso de CPU, uso de Memória e informações de Diversos. Por padrão o grupo Diversos está oculto e os grupos CPU e Memória estão recolhidos.

Cada grupo tem um menu de guias separado onde você pode alterar configurações relacionadas a esse grupo.

Na parte inferior do Painel de Controle existem dois botões, que serão explicados no menu de contexto do Painel de Controle, onde esses comandos também estão disponíveis.

O menu de contexto de Texturas

Este menu de contexto permite alterar quais grupos estão visíveis, algumas outras configurações relacionadas ao Painel de Controle, bem como alguns comandos relacionados ao Painel de Controle.

Figura 15.139. O menu de contexto de Texturas


Submenu Grupos

O submenu Grupos permite alterar quais grupos estão visíveis. Por padrão Cache, Swap, CPU e Memória estão visíveis, e Diversos está oculto, mas você pode escolher mostrar ou ocultar qualquer um deles aqui.

Submenu Intervalo de Atualização

O submenu Intervalo de Atualização permite alterar com que frequência as informações mostradas no Painel de Controle são atualizadas. O padrão é 0.25 segundos, mas você pode alterar isso para um período mais longo de até 4 segundos.

Submenu Duração do Histórico

O submenu Duração do Histórico permite alterar por qual período de tempo as informações são mostradas. O padrão é 60 segundos, mas você pode escolher valores entre 15 e 240 segundos.

Iniciar/Parar Gravação…

Isto também está disponível como um botão na parte inferior do Painel de Controle. Isso permite que você inicie ou pare de gravar um log de desempenho. Em certas situações, os desenvolvedores podem solicitar este log se você estiver enfrentando problemas relacionados ao desempenho. Este log pode ajudá-los a descobrir o problema. Quando você inicia a gravação, será solicitado que selecione um local e um nome de arquivo onde o log será salvo.

Adicionar Marcador…

Se você está gravando um log de desempenho, isso permite que você marque um evento específico no log. Será solicitado que você dê um nome a este evento. Isso pode facilitar para os desenvolvedores encontrarem a área problemática no seu log, porque os logs podem ficar bastante grandes. Isto também está disponível como um botão na parte inferior do Painel de Controle quando você está gravando um log de desempenho.

Adicionar Marcador Vazio…

Se você está gravando um log de desempenho, isso permite que você marque um ponto específico no log. Um marcador vazio será adicionado, significando que não será solicitado que você dê um nome a ele. Isso pode facilitar para os desenvolvedores encontrarem a área problemática no seu log, porque os logs podem ficar bastante grandes. Quando você está gravando, também pode usar o botão na parte inferior do Painel de Controle pressionando a tecla Shift para adicionar um marcador vazio.

Pré-definições

Redefinir dados cumulativos remove os dados de desempenho e começa do zero. Isto também está disponível como um botão na parte inferior do Painel de Controle quando você não está gravando um log de desempenho.

Aviso de Baixo Espaço de Swap…

Se esta opção estiver habilitada, o Painel de Controle será elevado ao topo se o seu espaço de swap estiver chegando ao limite.

Agora explicaremos cada grupo separadamente.

Cache

O Cache mostra qual parte do cache de tiles, cujo tamanho pode ser definido nas preferências de Recursos do Sistema, está sendo usado atualmente. Se o seu cache costuma estar perto do máximo, e você tem memória disponível suficiente, poderia considerar aumentar o tamanho do cache.

By default this shows the currently occupied part of the Cache, and the maximum cache size as set in preferences. What is shown can be changed in the Cache tab menu by clicking on . You can choose to show or hide Occupied size, Maximum size used since you started measuring, the cache Limit, the Compression ratio, and Hit/Miss ratio.

Swap

O Swap mostra o tamanho atual do swap de tiles em disco e qual parte dele está sendo usada atualmente. Também mostra o limite de tamanho do swap. Se o seu swap costuma ser usado, e você tem memória disponível suficiente, poderia considerar aumentar o tamanho do cache.

By default this shows the current Swap size and what part is occupied, as well as the Swap size limit. What is shown can be changed in the Swap tab menu by clicking on . You can choose to show or hide the Occupied size, the current swap file Size, the swap file size Limit, the Queued size (the amount planned to be written to the swap file), Read is the total amount read from the swap file, Written is the total amount written to the swap file, and the Compression ratio of the data written to the swap file.

CPU

A CPU mostra o uso atual da CPU.

By default this shows the current CPU usage. What is shown can be changed in the CPU tab menu by clicking on . You can choose to show or hide CPU Usage, and the total amount of time the CPU has been Active.

Memória

A Memória mostra a quantidade atual de memória usada pelo GIMP, a quantidade de memória física disponível (livre) e o tamanho total da sua memória física.

What is shown can be changed in the Memory tab menu by clicking on . You can choose to show or hide the occupied tile Cache, the total size of the Tile memory, the amount of memory Used, the size of the Available physical memory, and the physical memory Size.

Diversos

O grupo Diversos não é mostrado por padrão, mas precisa ser habilitado primeiro no menu de contexto do Painel de Controle. Ele mostra informações extras principalmente úteis para desenvolvedores.

By default all settings are shown, but what is shown can be changed in the Misc tab menu by clicking on . You can choose to show or hide total size of processed Mipmapped data, the number of Assigned worker threads, the number of Active worker threads, the number of Async (asynchronous) operations, the total size of Tile memory, the total size of Scratch memory, and the total size of TempBuf (temporary buffers).
