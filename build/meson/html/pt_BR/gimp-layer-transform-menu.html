7.45. O Submenu “Transformar”

The Transform submenu of the Layer menu contains commands which flip or rotate the selected layers of the image.

7.45.1. Ativando o submenu

You can access this submenu from the main menu through Layer → Transform.

7.45.2. O conteúdo do Submenu “Transformar”

O submenu Transformar contém os seguintes comandos:

  • Seção 7.46, “Espelhar horizontalmente”

  • Seção 7.47, “Espelhar verticalmente”

  • Seção 7.48, “Rotacionado 90° no sentido horário”

  • Seção 7.49, “Rotacionar 90° anti-horário”

  • Seção 7.50, “Rotacionar 180°”

  • Seção 7.51, “Rotação livre”

  • Seção 7.52, “Deslocamento”
