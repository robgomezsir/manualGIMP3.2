8.53. Paleta suave

8.53.1. Visão geral

Figura 16.216. Exemplo do filtro “Paleta suave”

Imagem original

Filtro “Paleta suave” aplicado


Este efeito cria uma paleta de faixas com cores da camada ativa ou seleção. O propósito principal deste filtro é criar um mapa de cores para ser usado com o filtro Chama.

Nota

Este comando somente funciona em imagens RGB. Se a imagem estiver em Tons de Cinza ou for Indexada, a entrada no menu é desativada.

8.53.2. Activating the Command

You can access this command from the main menu through Colors → Info → Smooth Palette….

8.53.3. Opções

Figura 16.217. Opções da “Paleta suave”


Width, Height

You can set palette dimensions for Width and Height. Dimensions are linked when the chain is not broken. You can also select the unit.

Search depth

Increasing Search depth (1 - 1024) will result in more shades in the palette.
