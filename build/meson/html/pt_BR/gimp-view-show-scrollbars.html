5.35. Exibir barras de rolagem

O comando Exibir barras de rolagens ativa e desativa a exibição de barras de rolagem. Pode ser útil desativar quando você estiver trabalhando no modo tela cheia.

You can set the default for the scrollbars in the Image Window Appearance Preferences.

5.35.1. Ativando o comando

You can access this command from the main menu through View → Show Scrollbars.
