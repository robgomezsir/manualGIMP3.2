7.46. Espelhar horizontalmente

The Flip Horizontally command reverses the selected layers horizontally, that is, from left to right.

It leaves the dimensions of the layers and the pixel information unchanged.

7.46.1. Ativando o comando

You can access this command from the main menu through Layer → Transform → Flip Horizontally.

Figura 16.106. Aplicando “Espelhar camada horizontalmente”

Antes de aplicar o comando

A camada depois de ter sido espelhada. É como se a imagem fosse refletida ao longo do eixo vertical central da camada.
