2.2. Validação

Quando você terminar de escrever, você deve validar seu trabalho:

  • Para um único arquivo você pode usar a seguinte linha de comando: xmllint --noout --nonet --valid your-file.xml. Este comando não mostra nada se seu arquivo estiver OK. Quando um erro é encontrado, ele mostrará uma mensagem indicando o tipo de erro e em que lugar do arquivo ele foi encontrado.

    Este comando pode ser usado para rapidamente verificar um arquivo XML. Ele pode falhar ou não encontrar alguns erros. No caso de referências externas a outros arquivos, ele também pode mostrar mensagens de erro incorretas, pois este comando verifica somente um único arquivo.

    (O editor Kate tem uma opção (um plug-in) para validar o arquivo XML ativo.)

  • Quando quiser verificar múltiplos arquivos ou todo o repositório do gimp-help, você deverá executar make validate-en. Você deverá receber a mensagem “No error”.

    Caso contrário, uma lista de erros de validação é exibida com os números das linhas referentes ao arquivo de registro en.xml que você pode encontrar na pasta /log.

    Abra este arquivo en.xml em um editor de texto, digite o comando de edição “pular para a linha” (o comando do editor Kate é Ctrl+G) e insira o número da linha para pular para a linha em questão no arquivo en.xml. Lá, você encontrará o erro.

    Se você trabalhou em vários arquivos XML, procure acima no arquivo en.xml para localizar (no campo “xml:base” da etiqueta “id”), em qual arquivo xml está o erro.

    Corrija o erro. Não se esqueça de salvar o arquivo e executar make validate-en novamente.

    Nota

    Um erro frequente é editar o arquivo de log en.xml em vez do arquivo XML.
