2.7. Você está tentando agir fora de uma camada

Figura 4.5. Grupo de camadas selecionado

Diálogo de camadas exibindo uma seleção flutuante.


How to tell: Check the Layers Dialog to see if the active layer is actually a Layer group. When a layer group is not empty, a small icon or appears in front of the layer group's thumbnail and name. Most actions don't work on a layer group, in which case an error message will show up: “Cannot paint on layer groups.”

Como corrigir: Você precisa ativar uma camada que não seja um grupo de camadas. Selecione uma camada clicando nela na caixa de diálogo Camadas. Se o grupo de camadas ativo tiver um sinal + na frente, ele está recolhido. Você pode clicar nele para expandir e mostrar as camadas individuais dentro desse grupo.
