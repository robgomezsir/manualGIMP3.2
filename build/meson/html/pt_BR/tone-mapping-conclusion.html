4. Conclusão

As fotografias tiradas sob a luz direta de sol forte normalmente são de cenas de alta faixa dinâmica, e o arquivo de câmera resultante geralmente requer mapeamento de tons cuidadoso para produzir uma imagem final satisfatória. A operação Exposição em ponto flutuante de grande profundidade de bits do GIMP fornece uma ferramenta muito útil para lidar com este tipo de imagem e, claro, é igualmente útil para qualquer imagem onde o objetivo é aumentar as sombras e os meios-tons sem estourar os tons claros.

A operação Exposição em ponto flutuante de grande profundidade de bits do GIMP combinada com uma máscara de camada adequada também pode ser usada para escurecer partes da imagem, seja movendo o seletor deslizante superior esquerdo de valor para a direita (escurece a imagem aumentando o contraste e também aumenta a saturação; requer mascaramento cuidadoso para evitar a produção de regiões de preto sólido), ou movendo o seletor deslizante inferior direito de valor para a esquerda (escurece a imagem diminuindo o contraste, útil para tirar a ênfase de partes da imagem).

Este é um tutorial específico para o GIMP. No entanto, a mesma técnica pode ser empregada usando o processador bruto PhotoFlow e possivelmente outros editores de imagem que permitem o processamento de ponto flutuante de 32 bits usando valores de canais RGB irrestritos. O interessante de usar essa técnica no PhotoFlow é que o PhotoFlow usa nós, o que permite a edição completamente não-destrutiva da máscara de tons de cinza invertida que é usada para recuperar o detalhe de tons claros após a aplicação de compensação de exposição positiva para aumentar a tonalidade das sombras e tons médios (mesmo se você fechar e reabrir a imagem, se você salvar o arquivo PFI da imagem).
