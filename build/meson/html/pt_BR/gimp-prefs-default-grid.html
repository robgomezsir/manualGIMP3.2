6.9. Grade de imagem padrão

Figura 15.105. Default Image Grid Preferences


This page lets you customize the default properties of GIMP's grid, which can be toggled on or off using View → Show Grid from the main menu.

6.9.1. Ativando o diálogo

The preferences dialog can be accessed from the main menu, through Edit → Preferences.

6.9.2. Opções

The settings here match those in the Configure Image Grid dialog, which can be used to reconfigure the grid for an existing image, by choosing Image → Configure Grid from the main menu. See the Configure Grid dialog section for information on the meaning of each of the settings.
