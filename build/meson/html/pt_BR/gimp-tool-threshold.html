8.54. Limiar

O filtro Limiar transforma a camada ou seleção atual em uma imagem em preto e branco, na qual pixels brancos representam os pixels da imagem em que o valor para o Canal escolhido está dentro do intervalo do limiar, e pixels pretos representam pixels com valor fora deste intervalo.

Você pode usá-lo para melhorar uma imagem em preto e branco (texto escaneado, por exemplo) ou para criar máscaras de seleção.

Nota

Como este filtro cria uma imagem em preto e branco, o antisserrilhamento da imagem original desaparece. Se isto for um problema, use a ferramenta Níveis no lugar.

8.54.1. Ativando o comando

  • You can access this command from the main menu through Colors → Threshold….

  • You can also access it by clicking the tool icon in the Toolbox if Threshold has been enabled as a tool (which is disabled by default). For this, please refer to Seção 6.13, “Caixa de ferramentas”.

8.54.2. Opções

Predefinições, Opções de Mistura, Preview, Merge filter, Split view
Nota

These options are described in Seção 8.1.2, “Funcionalidades Comuns de Cores”.

Canal

Isto lhe permite selecionar qual(is) canal(is) será(ão) usado(s) para aplicar o Limiar. O padrão é Valor, que usará todos os canais de cor, mas você também pode escolher usar um único canal: Vermelho, Verde, Azul e Alfa (disponível apenas quando a camada possui canal alfa), Luminância, ou RGB.

Linear histogram , Logarithmic histogram

Estes dois botões à direita da seleção de Canal lhe permitem escolher o tipo de histograma exibido.

Intervalo do limiar

A ferramenta Limiar providencia um gráfico visual, um histograma, do valor da intensidade da camada ou seleção ativa. Você pode definir o intervalo do limiar usando as caixas de entrada para mínimo e máximo ou clicando e arrastando no gráfico. Isto lhe permite separar uma parte da imagem com uma dada intensidade de um fundo com outra intensidade. Pixels dentro do intervalo são brancos, e os outros são pretos. Ajuste o intervalo para obter a seleção desejada em branco com fundo preto. O botão Automático pode ser usado para automaticamente ajustar o limiar.

8.54.3. Usando Limiar e Máscara Rápida para criar uma máscara de seleção

Sometimes an element you want to extract from an image can stand out well against the background. In this case, you can use the Threshold tool to select this element as a whole, and then use a Quick mask.

  1. First start decomposing your image into its RGB and HSV components by using the Decompose filter. A new grayscale image is created and the components are displayed as layers in the Layers Dialog. These layers come with a thumbnail but it is too small for an easy study. You can, of course, increase the size of this preview with the dialog menu (the small triangular button), but playing with the “eyes” is more simple to display the wanted layer in the decompose image. Select the layer that isolates the element the best.

    Figura 16.219. The original image, the decompose image and its Layers dialog


  2. Use a ferramenta Limiar na imagem decomposta. Movendo o cursor preto, ajuste o limiar para melhor isolar o elemento que você queira extrair. Isto provavelmente não será perfeito: melhoraremos o resultado com a máscara de seleção que vamos criar.

    Atenção

    Certifique-se de ter selecionado a camada certa ao usar a ferramenta Limiar: quando ela estiver aberta, você não poderá trocar para outra camada.

    Figura 16.220. A camada selecionada após o ajuste do limiar

    Conseguimos o melhor contorno para nossa flor. Há vários objetos vermelhos que precisamos remover.


  3. Certifique-se de que a imagem exibindo a camada selecionada está ativa e copie-a para a área de transferência com Ctrl+C.

  4. Now, make the original image active. Click the Quick Mask button at the bottom-left corner of the image window: the image gets covered with a red (default) translucent mask. This red color does not suit well to our image with much red: go to the Channels dialog, activate the “Quick mask” channel and change this color with the Edit Channel Attributes. Come back to the original image. Press Ctrl+V to paste the previously copied layer.

    Figura 16.221. A máscara


  5. Voilà. Your selection mask is ready: you can improve the selection as usual. When the selection is ready, disable the Quick mask by clicking its button again: you will see the marching ants around the selection.

    Figura 16.222. O resultado


    Usamos a Ampliação para trabalhar em nível de pixel, Seleção Livre para remover grandes áreas indesejadas, o lápis (para obter limites duros), tinta preta para remover áreas selecionadas, tinta branca para adicionar áreas selecionadas, especialmente para o caule.
