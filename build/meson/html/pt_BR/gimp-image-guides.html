6.31. “Guides” Submenu

O submenu de Guias contem vários comandos para a criação ou remoção de guias.

6.31.1. Ativando o submenu

You can access this submenu from the main menu through Image → Guides.

6.31.2. O conteúdo do submenu “Guias”

O o submenu Guias contém os seguintes comandos:

  • Seção 6.32, “Nova guia (por percentagem)”

  • Seção 6.33, “Nova guia”

  • Seção 6.34, “Novas guias a partir da seleção”

  • Seção 6.35, “Remove all Guides”
