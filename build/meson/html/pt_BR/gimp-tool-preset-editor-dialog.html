7.3. Editor de pré-definições de ferramentas

Figura 15.135. O Editor de Pré-definições de ferramentas


7.3.1. Ativando o diálogo

Você pode acessar esse diálogo das seguintes formas:

  • a click on the Edit this tool preset button in the button bar of the Tool Presets Dialog.

  • um clique-duplo num ícone de definição de ferramenta no diálogo de Definições de ferramenta (Opções de ferramenta)

  • um clique com o botão da direita no diálogo de Pré-definições de ferramentas para abrir um menu de contexto, e então escolher a opção Editar definição de ferramenta.

  • um clique no botão Salvar Predefinição de Ferramenta… do Diálogo de Opções de Ferramenta.

7.3.2. Usando o editor de definições de ferramenta

Você pode editar apenas as predefinições que criou; todas as opções de predefinições predefinidas estão desabilitadas. Quando você salva uma predefinição, ela é armazenada na primeira pasta gravável configurada em Predefinições de Ferramenta nas Preferências de Pastas.

Nesse diálogo você pode:

  • editar o nome da definição na caixa de texto

  • alterar o ícone da definição ao clicar no ícone da definição. Isso abre uma janela onde você pode escolher um novo ícone.

  • selecione os recursos a serem salvos clicando nas caixas de escolha.

The button bar at the bottom offers the following functionality:

  • Save the settings of the current tool preset.

  • Reset if you want to undo your changes.

7.3.3. O menu de contexto do diálogo de Definições de ferramentas

The Tool Preset Editor has a context menu that can be reached by clicking the tab menu button and then choosing Tool Preset Editor Menu. Besides two items that do the same as the save and restore buttons mentioned above, it only has one other option.

Editar paleta ativa

Quando habilitado, o editor de predefinição de ferramenta carregará automaticamente a predefinição de ferramenta ativa atualmente. Se estiver desabilitado, o editor de predefinição de ferramenta não mudará quando a predefinição de ferramenta ativa mudar.
