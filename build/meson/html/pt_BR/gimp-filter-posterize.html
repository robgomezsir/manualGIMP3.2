Níveis de Posterização

Aqui, “nível” significa “número de cores por canal”.

This slider and the + and - buttons allow you to set the number of levels (2-256) in each RGB channel that the tool uses to describe the active layer. The maximum total number of colors is the combination of these levels. A level of 3 will give 33 = 27 colors.
