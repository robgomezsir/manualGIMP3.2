6.14. Soft-Proof Profile

Soft-Proof Profile allows you to set a soft-proof profile for your image. Usually this will be a profile of a specific printer that will be used to print your image.

To get an idea how your image will look with the soft-proof profile enable View → Color Management → Proof Colors.

6.14.1. Ativando o comando

You can access this command from the main menu through Image → Color Management → Soft-Proof Profile….

6.14.2. Usage Notes for the Command

This command opens a dialog similar to that for assigning a Color Profile, where it shows the currently assigned soft-proof profile at the top, and lets you choose a new one below it.

By default None is selected as replacement. Clicking the drop-down will reveal a list of previously used color profiles that you can choose from, or you can Select color profile from disk…, that will open a dialog to browse for a profile located on your computer.
