5.6. Flip & Rotate (0°)

You can access this submenu from the main menu through View → Flip & Rotate (0°).

These commands change the view only, not on the image itself. If you want to change the image, go to: menuImage - Transform.

5.6.1. Reset Flip & Rotate

This command restores the view of the image to its original state.

Activate:

  • From the menu: View → Flip & Rotate (0°) → Reset Flip & Rotate.

  • Using the shortcut key !.

5.6.2. “Flip Horizontally” and “Flip Vertically”

These commands change the view by flipping the image horizontally or vertically. If one of these is enabled you will see a check mark in front of the command.

Activate:

  • View → Flip & Rotate (0°) → Flip Horizontally.

  • View → Flip & Rotate (0°) → Flip Vertically.

5.6.3. Rotate 15° clockwise

This command rotates the view of the image 15° clockwise.

Activate:

  • From the menu: View → Flip & Rotate (0°) → Rotate 15° clockwise.

5.6.4. Rotate 15° counter-clockwise

This command rotates the view of the image 15° counter-clockwise.

Activate:

  • From the menu: View → Flip & Rotate (0°) → Rotate 15° counter-clockwise.

5.6.5. Rotate 90° clockwise

This command rotates the view of the image 90° clockwise.

Activate:

  • From the menu: View → Flip & Rotate (0°) → Rotate 90° clockwise.

5.6.6. Rotate 90° counter-clockwise

This command rotates the view of the image 90° counter-clockwise.

Activate:

  • From the menu: View → Flip & Rotate (0°) → Rotate 90° counter-clockwise.

5.6.7. Rotate 180°

This command rotates the view of the image 180°.

Activate:

  • From the menu: View → Flip & Rotate (0°) → Rotate 180°.

5.6.8. Other rotation angle…

This command opens a dialog that allows you to set the exact angle of rotation for the view. You can set the angle in the numeric input field, or drag the pointer in the circle to the desired angle.

Activate:

  • From the menu: View → Flip & Rotate (0°) → Other rotation angle….
