3.16. Preencher contorno da seleção

Using this command, you can fill the current selection with the current foreground color or background color, or with the current pattern. It opens a dialog where you can choose between these options. This command is only active when a selection exists.

3.16.1. Ativando o comando

You can access this command from the main menu through Edit → Fill Selection Outline….

3.16.2. Opções

Esse comando faz aparecer uma janela de diálogo:

Figura 16.10. A janela de diálogo “Escolher estilo de preenchimento”


Foreground color

A cor de frente da caixa de ferramentas é usada.

Background color

The background color of the toolbox is used.

Textura

A textura ativa da caixa de ferramentas é usada.

Anti-serrilhamento

This option is enabled by default.
