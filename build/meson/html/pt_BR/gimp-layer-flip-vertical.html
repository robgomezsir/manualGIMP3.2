7.47. Espelhar verticalmente

The Flip Vertically command reverses the selected layers vertically, that is, from top to bottom.

It leaves the dimensions of the layers and the pixel information unchanged.

7.47.1. Ativando o comando

You can access this command from the main menu through Layer → Transform → Flip Vertically.

7.47.2. Exemplo

Figura 16.107. Aplicando “Espelhar camada verticalmente”

Antes de aplicar o comando

A camada depois de ter sido espelhada. É como se a imagem fosse refletida ao longo do eixo horizontal central da camada.
