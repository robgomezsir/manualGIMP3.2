7.7. Diálogo de pontos de amostragem

Enquanto que a ferramenta Seletor de Cores pode exibir informações de cor sobre um pixel, o diálogo de Pontos de amostragem pode exibir continuamente dados de até 4 pixels da camada ativa, ou de toda a imagem. Uma outra diferença importante é que os valores desses pontos são atualizados em tempo real, conforme você trabalha com a imagem.

7.7.1. Ativando o diálogo

O diálogo de “Buffers” é um diálogo de encaixe;veja a seção Seção 2.3, “Caixas de diálogo e de encaixe” para mais informações sobre como gerenciá-lo.

Você pode acessa-lo:

  • from the main menu: Windows → Dockable Dialogs → Sample Points.

  • from the Tab menu in any dockable dialog by clicking the tab menu button and selecting Add Tab → Sample Points.

7.7.2. Usando os pontos de amostragem

To create a sample point, Ctrl-click on one of the two measure rulers of the image window and drag the mouse pointer. Two perpendicular guides appear. The sample point is where both guides intersect. You can see its coordinates in the lower left corner of the status area at the bottom. Release the mouse button.

The image shows four already defined sample points and the reticle when you press Ctrl on a measure ruler and then click and drag.

Sample points are shown as a round mark with an order number. You can hide these marks by unchecking View → Show Sample Points in the main menu.

The “Sample Points” dialog does not automatically open when you create a sample point.

Você pode acessa-lo a partir de:

  • Using the Color Picker tool, click-and-drag the sample point up to a measure ruler to delete it.

  • Using a paint tool, Ctrl + click-and-drag the sample point up to a measure ruler to delete it.

By default, sampling is performed on all layers. If you want to sample on the active layer only, uncheck Sample Point Menu → Sample Merged from the tab menu.

7.7.3. Descrição do diálogo dos “Pontos de amostragem”

Figura 15.140. Diálogo de pontos de amostragem


Information about all sample points is displayed in this window.

A cor dos pontos de amostragem é exibida em um botão de cor.

Na lista flutuante, você pode escolher entre:

Pixel

Essa opção mostra os valores de Vermelho, Verde Azul e Alfa do pixel, como números entre 0 e 255. (até o GIMP 2.8)

RGB (%)

Essa opção mostra os valores de Vermelho, Verde Azul e Alfa do pixel como percentagens. Ela também exibe o valor da cor do pixel na notação hexadecimal.

RGB (0..255)

This choice displays the Red, Green, Blue and Alpha values of the pixel, as hexadecimal values. It also shows the hexadecimal value of the pixel's color.

Grayscale (%)

HSV

Essa opção mostra o Matiz em graus, bem como a Saturação, o Valor e o Alfa do pixel em porcentagens.

CIE LCh

CIE LAB

CIE xyY

CIE Yu'v'

CMYK

Essa opção mostra a cor do pixel como porcentagens das cores Ciano, Magenta, Amarelo, Preto e Alfa.

Data are supplied for every channel in the chosen color model. The Alpha is present only if the image has an Alpha channel.

Hex appears only when one of the RGB modes is selected. It displays the hexadecimal code of the HTML Notation.
