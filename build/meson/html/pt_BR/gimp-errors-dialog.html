7.5. Terminal de erros

O Terminal de erros oferece mais possibilidades do que uma simples “Mensagem do GIMP”. Esse é um registro de todos os erros ocorrendo enquanto o GIMP está rodando. Você pode salvar todo esse registro ou uma parte selecionada dele.

7.5.1. Ativando o diálogo

O diálogo de “Buffers” é um diálogo de encaixe;veja a seção Seção 2.3, “Caixas de diálogo e de encaixe” para mais informações sobre como gerenciá-lo.

Você pode acessa-lo:

  • from the main menu: Windows → Dockable Dialogs → Error Console;

  • from the Tab menu in any dockable dialog by clicking the tab menu button and selecting Add Tab → Error Console.

7.5.2. O diálogo de “Terminal de erros”

Figura 15.137. A “janela d e diálogo” terminal de erros


Limpar erros

Este botão limpa todas as mensagens do registro.

Atenção

Você não pode “desfazer” esta ação.
Salvar todos os erros

This button lets you save the error log to a file. A dialog window lets you choose the name and the destination directory of the error log file. See Seção 5.3, “Salvar arquivo” for more information on saving files.

Este botão permite que você salve todas as mensagens do registro. Você também pode selecionar uma parte das mensagens (clicando e arrastando o mouse, ou usando a tecla Shift junto com as Teclas seta) e salvar apenas esse trecho selecionado pressionado a tecla Shift ao apertar o botão.

Dica

Você também pode encontrar as ações desses botões no menu de contexto do diálogo, obtido ao se clicar com o botão direito do mouse na área de registro, ou a partir do menu de guias do diálogo de encaixe.

7.5.3. O menu de contexto de “Pincéis”

Além das funções mencionadas acima usando os botões, o menu de contexto tem as seguintes ações adicionais. Você pode acessar o menu de contexto clicando com o botão direito no console de erros.

Seleção

Este botão limpa todas as mensagens do registro.

Destacar

Este comando permite alterar quais tipos de mensagens destacarão o console de erros. Você pode habilitar ou desabilitar os três seguintes tipos de mensagens: Erros, Avisos e Mensagens.
