7.38. Cor para alfa

The Color to Alpha… command makes all pixels with a specified color in the current layer transparent. For more details see Seção 8.57, “Cor para Alfa…”.

Nota

This command only works on a single layer.

7.38.1. Ativando o comando

  • You can access this command from the main menu through Layer → Transparency → Color to Alpha….

  • You can also access it from the main menu through Colors → Color to Alpha… (see Seção 8.57, “Cor para Alfa…”).
