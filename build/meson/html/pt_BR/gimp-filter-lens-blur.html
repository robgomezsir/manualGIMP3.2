O desfoque de lente simula uma foto de uma câmera fora de foco.

3.4.2. Ativando o filtro

This filter is found in the main menu under Filters → Blur → Lens Blur….

3.4.3. Opções

Figura 17.15. Opções do diálogo do filtro Desfoque de Lente


Presets, “Input Type”, Clipping, Blending Options, Preview, Merge filter, Split view
Nota

Essas opções são descritas em Seção 2, “Recursos comuns”.
Aux

This allows you to select an additional input layer or channel, that will be used to compute the lens blur. Clicking on the square picture allows you to select from a list of available layers and channels. The Aux will only be used if this setting is enabled.

Raio

O tamanho do raio do desfoque.

Fator de tons claros

Intensidade relativa de tons claros.

Limiar de tons claros

Aqui, você pode definir os valores mínimo e máximo para tons claros. Ele pode ser definido ou pelo arraste dos triângulos pretos e brancos, ou pelo fornecimento dos valores exatos nos campos de entrada de números.

Cortar para a extensão da entrada

Se habilitado, limita a saída às dimensões da entrada.

Máscara linear

Se habilitado, usar valores de máscara lineares.
