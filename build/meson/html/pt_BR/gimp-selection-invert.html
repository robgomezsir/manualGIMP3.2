4.4. Inverter

O Comando Inverter inverte a seleção na camada atual em que se está trabalhando. Isto significa que todo o conteúdo da camada que estava previamente fora da área da seleção a partir de agora estará dentro e vice-versa. Se não havia seleção antes, o comando selecionará a camada toda.

Atenção

Do not confuse this command with the Invert colors command.

4.4.1. Ativando o comando.

  • You can access this command from the main menu through Select → Invert.

  • You can also use the keyboard shortcut Ctrl+I.

  • You can also access this command from the bottom bar of the Selection Editor, or through the Tab menu in the Selection Editor Menu.
