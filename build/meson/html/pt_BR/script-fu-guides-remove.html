6.35. Remove all Guides

O comando Remover todas as guias remove todas as guias da imagem. Clicar e arrastar uma ou duas guias até fora das imagem é uma forma mais rápida de remove-las. Este comando é útil se você posicionou várias guias.

6.35.1. Ativando o comando

You can access this command from the main menu through Image → Guides → Remove all guides.
