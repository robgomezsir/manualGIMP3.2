2.15. Criar novo modelo

O comando Criar novo modelo cria um modelo com as mesmas dimensões e espaço de cor que a imagem ativa. Aparece uma caixa de diálogo, que lhe pede para dar um nome ao novo modelo. Em seguida, o modelo será salvo e se torna disponível no diálogo de Nova Imagem. Se você der um nome que já existe, o GIMP gera um nome exclusivo anexando um número ao nome dado. Você pode usar o diálogo de Modelos para modificar ou excluir modelos.

2.15.1. Ativando o comando

You can access this command from the main menu through File → Create Template…. There is no default keyboard shortcut.
