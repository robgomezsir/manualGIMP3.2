8.12. Inverter

O comando Inverter inverte todas as cores e valores de brilho dos pixels da camada ativa, como se a imagem fosse convertida num negativo. Áreas escuras se tornam claras, e áreas claras ficam escuras. Os matizes são substituídos por suas cores complementares. Para maiores informações sobre cores, veja a entrada no Glossário sobre Modelo de Cores.

Atenção

Não confunda este comando com o comando de Inverter seleção.

8.12.1. Ativando o comando

You can access this command from the main menu through Colors → Invert.
