8.4. Laplace

8.4.1. Visão-geral

Figura 17.173. Exemplo aplicativo do filtro Laplace

Imagem original

Filter applied


Este filtro detecta as bordas da imagem usando o método laplaciano, que produz bordas finas, do tamanho de um pixel.

8.4.2. Activating the Filter

This filter is found in the main menu under Filters → Edge-Detect → Laplace….
