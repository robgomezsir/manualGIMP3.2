Figura 15.100. Preferências do gerenciamento de cor


Esta página deixa você configurar o gerenciamento de cor do GIMP.

6.4.1. Ativando o diálogo

The preferences dialog can be accessed from the main menu, through Edit → Preferences.

6.4.2. Opções

Algumas das opções permitem que você escolha um perfil de cores a partir de um menu. Se o perfil desejado não estiver no menu, no entanto, você pode adicioná-lo clicando no item Selecione o perfil de cores do disco.

Dica

Arquivos que contêm perfis de cores são facilmente reconhecíveis por seu sufixo . icc. Além disso eles são normalmente armazenados todos juntos em poucos locais. Se você estiver executando o GIMP no Mac OS X, você deve tentar /Library/ColorSync/Profiles/ e Library/Printers/[fabricante]/Profiles.
Modo de exibição da imagem

Usando esta opção, você pode decidir como o gerenciamento de cores GIMP opera. Há três modos que você pode escolher:

  • No color management: Choosing this disables color management in GIMP completely.

  • Color managed display: This enables GIMP color management and provides a fully corrected display of the images according to the given color profile for the display.

  • Soft-proofing: When choosing this option, you enable GIMP color management not only to apply the profile for the display, but also for the selected printer simulation profile. Doing so, you can preview the color results of a print with that printer.

    Nota

    Por favor observe que o gerenciamento de cores do GIMP é usado apenas para melhorar a exibição de imagens e a incorporação de perfis ao salvar ou exportar arquivos de imagem. Sobretudo as opções escolhidas neste diálogo não são usadas de maneira nenhuma na impressão de dentro GIMP. Isso ocorre porque a impressão é uma tarefa especial feita por um mecanismo de impressão mais especializado que não é parte do GIMP.

Gerenciamento de cores

Conta gotas

  • Nenhum: O GIMP usa o perfil colorimétrico do seu monitor.

  • Selecionar perfil de cor do disco: escolha um perfil que você tenha disponível no seu computador.

  • Try to use the system monitor profile: When enabled, GIMP will try to use the display color profile supplied by the system. The configured monitor profile is then only used as a fallback.

Mostrar métodos de renderização

Esta opção é sobre como as cores são convertidas do espaço de cor da sua imagem para o seu dispositivo de exibição. Quatro modos estão disponíveis: “Perceptual”, “Colorimetria relativa”, “Saturação” e “ Colorimetria absoluta”.

A colorimetria relativa geralmente é a melhor escolha (padrão). A menos que você use um perfil de monitor LUT (a maioria dos perfis de monitor é matriz), escolher a intenção perceptual na verdade resulta em colorimetria relativa. Veja também Intenção de renderização .

Usar compensação de ponto preto

Esta opção está marcada por padrão. Use compensação de ponto preto a menos que você tenha um motivo para não usar.

Optimize image display for

Two options: Speed and Precision / Color Fidelity. “Speed” is activated by default. If not, image display might be better at the cost of speed.

Soft-Proofing

A prova de cores maciça é um mecanismo que permite que você veja na sua tela como a impressão em papel ficará. Mais geralmente, é uma prova de cores maciça do espaço de cor da sua imagem para outro espaço de cor (impressora ou outro dispositivo de saída).

Optimize soft-proofing for

Two options: Speed and Precision / Color Fidelity. “Speed” is activated by default. If not, soft-proofing might be better at the cost of speed.

Marcar cores fora da gama

Quando esta caixa está marcada, a prova de cores maciça marcará as cores que não podem ser representadas no espaço de cor de destino. À direita há um botão de cor que você pode clicar para abrir um seletor de cores para escolher a cor que deseja usar para marcar cores fora da gama.

Preferências

Conta gotas

O padrão é “Nenhum”, o que faz com que o perfil RGB integrado seja usado. Você pode selecionar outro perfil de cor de espaço de trabalho RGB do disco: ele será oferecido ao lado do perfil integrado quando um perfil de cor puder ser escolhido.

Conta gotas

O padrão é “Nenhum”, o que faz com que o perfil Grayscale integrado seja usado. Você pode selecionar outro perfil de cor de espaço de trabalho Grayscale do disco: ele será oferecido ao lado do perfil integrado quando um perfil Grayscale puder ser escolhido.

Conta gotas

O padrão é “Nenhum”. Você pode selecionar um perfil de cor de espaço de trabalho CMYK do disco para converter RGB para CMYK.

Políticas

Comportamento ao abrir arquivo

Default is “Ask what to do”. You can also select “Keep embedded profile”, “Convert to built-in sRGB or grayscale profile”, or “Convert to preferred RGB or grayscale profile (defaulting to built-in)” to indicate how to treat embedded color profiles when opening an image file.
