7.14. Submenu “Pilha”

The layer stack is simply the list of layers in the Layers dialog. The Stack submenu contains operations which either allow you to change which layers are selected, or change the position of the selected layers in the layer stack. If your image has only one layer, these commands are disabled.

7.14.1. Ativando o submenu

You can access this submenu from the main menu through Layer → Stack.

7.14.2. O conteúdo do Submenu “Pilha”

O submenu Pilha contém os seguintes comandos:

  • Seção 7.15, “Select Previous Layers”

  • Seção 7.16, “Select Next Layers”

  • Seção 7.17, “Selecionar camada do topo”

  • Seção 7.18, “Selecionar a camada do fundo”

  • Seção 7.19, “Raise Layers”

  • Seção 7.20, “Lower Layers”

  • Seção 7.21, “Layers to Top”

  • Seção 7.22, “Layers to Bottom”

  • Seção 7.23, “Reverse Layer Order”
