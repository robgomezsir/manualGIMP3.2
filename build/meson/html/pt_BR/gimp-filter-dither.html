8.58. Reticular

Este filtro pode reduzir o número de cores numa imagem pela redução de níveis por canal (cores e alfa). Diferentes métodos de reticulação podem ser especificados para contrabalançar bandeamento induzido por quantização.

8.58.1. Ativando o comando

You can access this command from the main menu through Colors → Dither….

8.58.2. Opções

Figura 16.230. Diálogo do filtro Reticular


Predefinições, Tipo de Entrada, Corte, Opções de Mistura, Preview, Merge filter, Split view
Nota

These options are described in Seção 8.1.2, “Funcionalidades Comuns de Cores”.

Red levels, Green levels, Blue levels, Alpha levels

These sliders allow you to set the number of levels for the respective red, green, blue and alpha channels.

Método de reticulação

Aqui você pode especificar o método de reticulação a se usar.

Nenhum

Nenhuma reticulação será realizada na imagem.

Floyd-Steinberg

Este é o método de reticulação mais comumente usado e o padrão para este filtro. Para mais informações, veja Reticulação Floyd-Steinberg na Wikipedia.

Bayer

A Matriz Bayer é outro método comum de reticulação usado para reduzir o número de cores. O algoritmo é caracterizado por padrões hachurados perceptíveis no resultado. Para mais informações, veja Reticulação ordenada na Wikipedia.

Random, Random Covariant

Estes métodos de reticulação usam aleatorização dos valores de pixel para reduzir o número de cores.

Arithmetic add, Arithmetic add covariant, Arithmetic xor, Arithmetic xor covariant

Estes métodos de reticulação são espacialmente estáveis, baseados em números mágicos e aritmética. Para mais informações, veja uma reticulação.

Blue Noise, Blue Noise Covariant

Estes métodos de reticulação usando o tal ruído azul foram percebidos como sendo os menos feios e distrativos. Para mais informações, veja Reticulação em processamento de imagem na Wikipedia.

Random seed, New Seed

This option controls the randomness of the filter. The Random seed box lets you manually enter a seed for the randomization algorithm used. You can also generate a random seed by pressing the New Seed button. If the same random seed is used in the same situation, the filter produces exactly the same results. A different random seed produces different results.
