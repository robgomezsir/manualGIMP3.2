2.3. O que fazer e o que não fazer

Um erro comum quando você está lidando com o Script-Fu é que você simplesmente os aciona e pressiona o botão OK. Quando nada acontece, você provavelmente acha que o script está com problema ou erro, mas é bastante provável que não haja nada errado com ele.

A simple way to see if the script did anything is to check Edit → Undo. If your script made any changes to the current image, it will be listed as the last undo action.
