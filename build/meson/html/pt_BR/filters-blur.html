3. Filtros de desfocar

3.1. Introdução

Blur filters blur images, or parts of them, in various ways. If there is a selection, only the selected parts of an image will be blurred. There may, however, be some leakage of colors from the unblurred area into the blurred area.

Figura 17.2. Imagem original


To help you pick the one you need, we will illustrate what some of the filters do when applied to the image shown above. These are, of course, only examples: most of the filters have settings that allow you to vary the magnitude or type of blurring.

Figura 17.3. Desfoque Gaussiano


The most commonly used blur filter is the Gaussian Blur. Don't let the word “Gaussian” throw you off: this filter is the most basic kind of blur. It allows you to create a strong blur in a relatively short time.

Figura 17.4. Pixelizar


The Pixelize filter produces the well-known “Abraham Lincoln” effect by turning the image into a set of large square pixels. (The Oilify filter, in the Artistic Filters group, has a similar effect, but with irregular blobs instead of perfectly square pixels.)

Nota

You can find a nice explanation of the Abraham Lincoln effect at [BACH04]. You will see Salvador Dali's painting “Gala Contemplating the Mediterranean Sea” turning into Abraham Lincoln's portrait when looking at it from a distance.

Figura 17.5. Desfoque Gaussiano Seletivo


The Selective Gaussian Blur filter allows you to set a threshold so that only pixels that are similar to each other are blurred together. It is often useful as a tool for reducing graininess in photos without blurring sharp edges. (In the example, note that the graininess of the background has been reduced.) This filter is much slower than a Gaussian Blur, though, so only consider using it when you really need the selectivity.

Figura 17.6. Desfoque de Movimento Circular


The Circular Motion Blur filter blurs in a radial direction around a center that you can set.

Figura 17.7. Desfoque de Movimento Linear


The Linear Motion Blur filter blurs in a linear direction that you can set.

Figura 17.8. Desfoque de movimento de aproximação


The Zoom Motion Blur filter blurs in a radial direction around a center that you can set, while at the same time enlarging further away from the center.

Finally, the Tileable Blur filter is really the same thing as a Gaussian Blur, except that it wraps around the edges of an image to help you reduce edge effects when you create a pattern by tiling multiple copies of the image side by side.
