6.26. Slice Using Guides

The Slice Using Guides command slices up the current image, based on the image's guides. It cuts the image along each guide, similar to slicing documents in an office with a guillotine (paper cutter) and creates new images out of the pieces. For further information on guides, see Seção 1.2, “Guias”.

6.26.1. Ativando o comando

You can access this command from the main menu through Image → Slice Using Guides.
