6.6. Playground Experimental

Figura 15.102. Experimental Playground Preferences


6.6.1. Ativando o diálogo

The preferences dialog can be accessed from the main menu, through Edit → Preferences.

6.6.2. Opções

Hardware Acceleration

The Playground settings are only available if you have explicitly started GIMP with the “--show-playground” command line argument, or if you have previously enabled one of the experimental settings in Playground.

Usar OpenCL

OpenCL é um acrônimo para Open Computing Language (veja Wikipedia). Esta opção tenta melhorar a velocidade de processamento de certas operações usando a GPU (unidade de processamento gráfico) em vez da CPU.

Atenção

Este é um recurso muito experimental que é conhecido por falhar frequentemente! Habilite apenas se pretender trabalhar para melhorá-lo e não se esqueça de que você o habilitou.

Experimental

Ferramenta de Deformação de N Pontos

Esta ferramenta permite criar uma deformação semelhante a borracha da imagem usando pontos.

Ferramenta de Clonagem Sem Costura

Este botão limpa todas as mensagens do registro.

Paint Select Tool

This tool lets you paint over an image to progressively create a selection.

Atenção

Estas são ferramentas experimentais que são conhecidas por falhar, causar lentidão e não funcionar como esperado! Habilite apenas se quiser testar, ou pretender trabalhar para melhorá-las, e não se esqueça de que você as habilitou.
