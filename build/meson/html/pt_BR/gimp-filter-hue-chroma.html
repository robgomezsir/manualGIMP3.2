8.4. Matiz Croma

O filtro Matiz-Croma é outra forma de modificar saturação. Explicações claras sobre croma e saturação podem ser encontradas em https://ninedegreesbelow.com/photography/changing-saturation-using-lch-chroma.html .

8.4.1. Ativando o comando

You can access this command from the main menu through Colors → Hue-Chroma….

8.4.2. Opções

Figura 16.125. Opções de Matiz-Croma


Predefinições, Opções de Mistura, Preview, Merge filter, Split view
Nota

These options are described in Seção 8.1.2, “Funcionalidades Comuns de Cores”.

Matiz

The slider and the + and - buttons allow you to select a hue in the color wheel (-180°, 180°).

Croma

“Croma” é a pureza da cor. Mover este controle torna as cores mais ou menos puras.

Brilho

This slider and the + and - buttons allow you to select a value (luminosity): -100, 100.
