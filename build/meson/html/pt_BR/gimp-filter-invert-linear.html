8.13. Inversão Linear

O comando Inversão Linear inverte todos os componentes de cor, exceto o canal alfa, na camada atual em luz linear. Áreas escuras se tornam claras e áreas claras se tornam escuras.

Atenção

Não confunda este comando com o comando de Inverter seleção.

8.13.1. Ativando o comando

You can access this command from the main menu through Colors → Linear Invert.
