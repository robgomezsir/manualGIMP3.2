5.54.2. Opções

Tipo de origem

Isso seleciona o tipo de imagem que você está tentando exportar. Presumivelmente isso ajudará a decidir a melhor maneira de comprimir a imagem.

As opções são: Padrão, Imagem para fotos digitais, como retratos ou fotos internas, Foto para fotografia ao ar livre com iluminação natural, Desenho para desenho à mão ou linha, com detalhes de alto contraste, Ícone para imagens coloridas de tamanho pequeno, e Texto para imagens que contêm principalmente texto.

Sem perda

Quando marcado, a imagem será salva de forma a manter a qualidade original. Isso desabilita as configurações Qualidade da imagem e Qualidade do alfa. Quando desmarcado, a imagem será salva com base nas configurações de qualidade abaixo, o que pode causar alguma perda de qualidade, mas em uma melhor taxa de compressão. Este é o padrão.

Image quality, Alpha quality

Estas configurações determinam em que qualidade a imagem será salva. Uma qualidade de imagem mais alta geralmente significa um tamanho de arquivo maior. Quando o tamanho do arquivo é importante, você pode verificar se uma qualidade menor ainda é suficiente para seus propósitos.

Use Sharp YUV

When checked, a sharper and more accurate RGB to YUV conversion method is used to export the image. This can better preserve fine details like thin lines in the final image. Setting this option can increase the export time for an image, and it is only available when Lossless is not checked.

Save animation

When enabled, an animation will be created, where each layer is a separate frame in the animation.

When working on an animation, the name of the layer can be used to specify certain parameters. For more details see exporting animations.

Metadados (editar)

You can click the “(edit)” link to open the metadata editor to change or add any metadata that you want to be included in the image. Note: you will also still need to enable the relevant metadata saving options listed below.

The metadata settings in the export dialog override the default values set in your Metadata Export Preferences.

Salvar dados de EXIF

When this option is enabled, EXIF metadata will be saved in the exported image.

Salvar dados XMP

When this option is enabled, IPTC metadata will be saved in the exported image.

Salvar dados XMP

When this option is enabled, XMP metadata will be saved in the exported image.

Conta gotas

When this option is enabled, the color profile will be saved in the exported image.

Miniatura da camada

When this option is enabled a thumbnail will be saved in the exported image as part of the EXIF metadata. This will also cause certain EXIF tags to be saved, even if you have disabled saving EXIF metadata.
