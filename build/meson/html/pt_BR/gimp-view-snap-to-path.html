5.29. Snap to Active Path

Caso essa opção esteja ativada, ao mover a seleção ou camada, elas parecem puxar para o próximo ponto de ancoragem do vetor ativo ao aproximar. Isto é útil para localizar com precisão os elementos de uma imagem.

5.29.1. Ativando o comando

You can access this command from the main menu through View → Snap to Active Path.
