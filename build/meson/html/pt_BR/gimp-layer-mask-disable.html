7.30. Disable Layer Masks

The Disable Layer Masks command allows you to temporarily disable the effect of the selected layer masks. A red border will be shown around the thumbnail of the selected layer masks in the Layers Dialog. To enable the layer masks use the same command again.

7.30.1. Ativando o comando

  • You can access this command from the main menu through Layer → Mask → Disable Layer Masks.

  • From the Layers Dialog, you can access it through the Disable Layer Masks command of its context menu; or by holding down the Ctrl+Alt keys and clicking on the layer mask's thumbnail in the Layers Dialog.
