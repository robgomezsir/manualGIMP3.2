4.12. Espelhar

A ferramenta de Espelhar dá a habilidade de espelhar camadas ou seleções na direção vertical ou horizontal. Quando uma seleção é espelhada, é criada uma Seleção flutuante. Você pode usar esta ferramenta para criar reflexos.

4.12.1. Ativando a ferramenta

There are different possibilities to activate the tool:

  • A partir do menu da janela de imagens, em:Ferramentas → Ferramentas de transformação → Mover

  • Ao clicar no ícone da ferramenta: na caixa de ferramentas

  • Ou usando o atalho de teclado Shift+F.

4.12.2. Teclas modificadoras (Padrões)

Ctrl

Ctrl deixa você trocar os modos da ferramenta entre horizontal e vertical.

4.12.3. Opções

Figura 14.125. Opções de ferramenta


Normally, tool options are displayed in a window attached under the Toolbox as soon as you activate a tool. If they are not, you can access them from the main menu through Windows → Dockable Windows → Tool Options which opens the option window of the selected tool. The available tool options can also be accessed by double clicking the corresponding tool icon in the Toolbox.
